# Mova algorithms

`mova-algorithms` is a Rust library of two hundred deterministic algorithms, implemented for Mova using only the standard library. It forbids unsafe code and has no crate dependencies. Implementations and test fixtures are repository-owned; no LeetCode problem statements, solutions or imports are included. GCD reuses the Euclidean recurrence already present in Mova's math crate. The existing [Elamur Cosmic License](../LICENSE.md) applies.

Each algorithm has its own `src/<algorithm>/` directory. Each directory holds its implementation in `mod.rs`, executable checks in `tests.rs`, and adjacent `mod.rs.groupant/` and `tests.rs.groupant/` models. The shared public boundary remains `src/lib.rs` with `src/lib.rs.groupant/`.

For example:

```text
algorithms/src/bfs/
├── mod.rs
├── mod.rs.groupant/
├── tests.rs
└── tests.rs.groupant/
```

Import public modules through `mova_algorithms`. For example:

```rust
use mova_algorithms::{binary_search, merge_sort};

let mut values = [7, 2, 7, 1];
merge_sort::merge_sort(&mut values);
assert_eq!(binary_search::binary_search_first(&values, &7), Some(2));
```

Costs below count comparisons, clones and fixed-width arithmetic as constant-cost operations. Space excludes input and returned output unless stated. Here `n,m` are sequence lengths, `V,E` are vertex/edge counts, `C` is knapsack capacity, `L,R` are bipartite partition sizes, `S` is a counting-sort span, `w` is a window width, and `N` is a sieve limit.

| Algorithm and public API | Time; auxiliary space | Contract and boundaries |
| --- | --- | --- |
| Binary search: `binary_search::{lower_bound, binary_search_first}` | O(log(n+1)); O(1) | Sorted `&[T]`, `T: Ord`; sorting is not checked. Lower bound returns the first index with value >= target, or n. First-match returns `Option<usize>`; duplicates choose the first. Empty input gives 0 / None. |
| Stable merge sort: `merge_sort::merge_sort` | O(n log(n+1)); O(n) elements plus O(log(n+1)) stack | Mutates `&mut [T]`, `T: Ord + Clone`. Equal-key order is preserved. Empty/singleton inputs need no scratch allocation. Requires lawful ordering and value-preserving cloning. |
| GCD: `gcd::gcd` | O(1+log(min(a,b)+1)); O(1) | Two u64 inputs, u64 output. `gcd(0,0)=0`; `gcd(a,0)=a`. No signed conversion or multiplication. |
| Breadth-first search: `bfs::bfs` | O(V+E); O(V) | Directed adjacency lists and source index; returns `Result<Vec<Option<usize>>, BfsError>`. None means unreachable. Rejects invalid source, then every invalid edge, including unreachable edges. Empty graph has no valid source. |
| Dijkstra: `dijkstra::dijkstra` | O(V+E log(E+1)); O(V+E) | Directed edges with u64 weights; exact u128 distances or None. Zero weights allowed. Validates source and all endpoints; checked addition reports `DistanceOverflow`. Lazy heap space includes stale entries. |
| Topological sort: `topological_sort::topological_sort` | O(E+V log(V+1)); O(V) | Returns the lexicographically smallest vertex ordering. Parallel edges count separately; cycles and invalid endpoints return typed errors. All endpoints are validated before cycle processing. Empty graph returns an empty ordering. |
| Disjoint sets: `disjoint_set::DisjointSet` | O(n) construction; amortized O(alpha(n)) per find/union/query; O(n) storage | Fixed universe `0..n`; `new`, `find`, `union`, `connected`, `components`, `len`, `is_empty`. Invalid indices return `IndexError` without changing representation. Union reports whether components merged. Equal-size roots choose the smaller index; representatives need not be minimum members. |
| KMP matching: `kmp::find_all` | O(n+m); O(m), plus returned matches | Byte slices; returns every matching byte offset, including overlaps. Empty needle matches all n+1 boundaries. UTF-8 byte offsets are not character indices. |
| 0/1 knapsack: `knapsack::{Item, max_value}` | O((n+1)(C+1)); O(C+1) | Each item has usize weight and u64 value; returns `Result<u128, Error>`. Each item is selectable once, including zero-weight items. Equal items are separate choices. Capacity dimension overflow and allocation refusal return errors. Exact value accumulation assumes supported Rust targets with usize <=64 bits. |
| Levenshtein distance: `levenshtein::distance` | O(1+nm); O(min(n,m)) | Generic `T: Eq` slices; unit insertion/deletion/substitution costs, usize result. Empty input returns the other length. Caller chooses bytes, Unicode scalars or graphemes. With both inputs nonempty, usize::MAX length is rejected by panic. |
| Heap sort: `heap_sort::heap_sort` | O(n log(n+1)); O(1) | In-place lawful `Ord`, no Clone bound. Deterministic but not stable for equal-key payloads. |
| Selection: `quickselect::select_nth` | O(n²) worst case; O(1) | Mutates a slice to place the requested rank; prefix <= selected <= suffix. Invalid rank returns None without mutation. Deterministic pivot; no unconditional linear-time claim. |
| Strict LIS: `longest_increasing_subsequence::indices` | O(n log(n+1)); O(n) | Returns original indices of one maximum-length strictly increasing subsequence. Equal minimum tails use the latest index; earliest lexicographic witness is not promised. |
| Strong components: `strongly_connected_components::components` | O(V+E+V log(V+1)); O(V+E) | Iterative traversal with all endpoints validated. Vertices inside each component are sorted; components are ordered by their smallest vertex. |
| Minimum spanning forest: `kruskal::minimum_spanning_forest` | O(V+E log(E+1)+E alpha(V)); O(V+E) | Undirected u64-weight edges. Returns original edge indices, u128 total and component count. Ties use weight, canonical endpoints, then original index; self loops ignored after validation. |
| All-pairs shortest paths: `floyd_warshall::floyd_warshall` | O(V³+E); O(V²) including output | Nonnegative u64 weights, exact optional u128 distances. Diagonal zero, parallel-edge minimum, global endpoint validation and checked candidate addition. |
| Dynamic sums: `fenwick::Fenwick` | O(n) build, O(log(n+1)) update/query; O(n) | i64 points with exact i128 sums on usize<=64 targets. Invalid or overflowing point updates preserve state. Prefix/range queries use exclusive ends; empty sums are zero. |
| Immutable minima: `sparse_table::SparseTable` | O(n log(n+1)) build, O(1) query; O(n log(n+1)) | `Ord + Clone`; leftmost equal minimum. Nonempty half-open ranges return a reference; empty, reversed and out-of-bounds ranges return None. |
| Integer square root: `integer_sqrt::integer_sqrt` | At most 33 iterations; O(1) | Exact floor root for every u64, with u128 square comparisons and no floating point. |
| Modular power: `modular_power::modular_power` | At most 64 exponent iterations; O(1) | u64 base/exponent/modulus with exact u128 products. Modulus zero errors; modulus one returns zero; exponent zero returns 1 modulo the modulus. |
| Signed shortest paths: `bellman_ford::bellman_ford` | O(V(V+E)); O(V) | Directed i64 weights; optional exact i128 distances. Validates source then all endpoints, including unreachable edges. Reports reachable negative cycles and checked-add overflow; unreachable negative cycles do not fail the call. |
| Bipartite matching: `bipartite_matching::bipartite_matching` | O((L+1)(L+R+E)); O(L+R) | Left adjacency lists and right vertex count; returns one optional right mate per left vertex. Maximum cardinality with deterministic traversal ties; no lexicographic minimality guarantee. Validates every endpoint; duplicate edges allowed. |
| Z prefix matches: `z_algorithm::z_algorithm` | O(n); O(1), plus O(n) output | Byte slices; each entry is the common-prefix length with that suffix. First entry is n; empty input returns an empty vector. Offsets count bytes. |
| Palindrome radii: `manacher::{manacher, PalindromeRadii}` | O(n); O(1), plus O(n) output | Byte slices; odd radius includes its center, even radius is centered before its index. Returns both maximal-radius vectors; empty input returns two empty vectors. |
| Dynamic minima: `segment_tree::SegmentTree` | O(n) build, O(log(n+1)) update/query; O(n) | `Ord + Clone`; point replacement and nonempty half-open range queries with leftmost minimum ties. Invalid updates preserve state; empty, reversed and out-of-bounds queries return None. Trait panics and allocation failure are outside the typed error contract. |
| Sliding minima: `sliding_window_minimum::minimum_indices` | O(n); O(w), plus output | `Ord` slices; source indices of leftmost minima for complete windows. Zero or oversized widths return an empty vector. No input mutation or Clone bound. |
| Counting sort: `counting_sort::counting_sort` | O(n+S); O(S) | Mutable usize slice and caller bucket budget. Histogram spans min..=max; range overflow, budget excess and allocation refusal return typed errors before mutation. Empty input needs no buckets; a singleton needs one. |
| Radix sort: `radix_sort::radix_sort` | O(8(n+256)); O(n+256) | Mutable u64 slice; eight stable LSD byte passes, independent of host endianness. Scratch reserve failure returns TryReserveError before mutation. Scalar API exposes no attached payloads. |
| Extended GCD: `extended_gcd::{extended_gcd, Bezout}` | O(1+log(max(a,b)+1)); O(1) | u64 inputs; u64 gcd and i128 coefficients satisfying a*x+b*y=gcd. Deterministic coefficients; (0,0) returns three zeros. |
| Prime sieve: `sieve::sieve` | O(N log log N) for N>=3; O(N) | Inclusive usize limit; returns ascending primes. Limits below two return empty output. Checked storage sizing and fallible allocation return SizeOverflow or AllocationFailed. |
| Binary-weight paths: `zero_one_bfs::zero_one_bfs` | O(V+E); O(V+E) including stale deque entries | Optional usize distances; source, all endpoints and all u8 weights validated. Weights zero or one; zero cycles allowed. |
| DAG paths: `dag_shortest_paths::shortest_paths` | O(E+V log(V+1)); O(V+E) | Signed i64 weights, optional checked i128 distances. Reuses deterministic topological sort; even unreachable cycles reject. |
| Multi-pattern matching: `aho_corasick::AhoCorasick` | Search O(n log 256+z); stored automaton O(M+H+P) | Byte matches ordered by (end, pattern ID), overlaps, duplicate and empty patterns. M total pattern bytes, H inherited outputs, P pattern count, z emitted matches. Sparse construction and output sorting have the fuller bound in the leaf model. |
| Suffix array: `suffix_array::suffix_array` | O(n log²(n+1)); O(n) | Byte offsets sorted by suffix; empty suffix excluded. Prefix doubling with comparison sort. |
| Common subsequence: `longest_common_subsequence::length` | O(1+nm); O(min(n,m)) for nonempty inputs | Lawful Eq, exact length in one row; no witness. Dimension overflow panics; allocation/trait panics follow Rust behavior. |
| Interval scheduling: `weighted_interval_scheduling::select` | O(n log(n+1)); O(n) | Positive-length half-open i64 intervals, u64 weights, checked u128 optimum and original-index witness. Adjacency allowed; sorted-DP ties skip candidate. |
| Convex hull: `convex_hull::{Point,convex_hull}` | O(n log(n+1)); O(n) | Exact i32 points with i128 cross products. CCW extreme vertices from lexicographic minimum; duplicate/interior collinear points omitted. |
| Closest pair: `closest_pair::closest_pair` | O(n log²(n+1)); O(n) | Shares hull Point type; exact u128 squared distance and lexicographically smallest original-index pair. Fewer than two points gives None. |
| Prime factors: `prime_factorization::factorize` | O(sqrt(n)) trial divisions; O(log(n+1)) output | Ascending prime/exponent pairs; one empty, zero errors. Division-based bounds avoid overflow; large primes can be slow. |
| Generalized CRT: `chinese_remainder::solve` | O(k log U); O(1) auxiliary, U=u64::MAX | Noncoprime moduli allowed; normalized combined u64 class or None. Zero moduli preflight, then left-to-right checked merge; overflow can precede later contradiction. Empty system 0 mod 1. |
| Bridges: `bridges::bridges` | O(V+E); O(V+E) | Undirected indexed multigraph, loops and parallel edges; sorted original edge IDs, global endpoint validation. Iterative lowlink traversal. |
| Articulation points: `articulation_points::articulation_points` | O(V+E); O(V+E) | Reuses Edge; sorted cut vertices with removed-vertex connectivity semantics, including disconnected graphs. |
| Euler trail: `eulerian_trail::eulerian_trail` | O(V+E); O(V+E) | Optional deterministic edge-ID trail; nonisolated support connected, zero/two odd degrees. Loops count twice. Empty universe yields empty trail; edgeless nonempty universe starts at zero. |
| Maximum flow: `max_flow::max_flow` | O(V+E+VE(V+E)); O(V+E) | Edmonds-Karp with u64 capacities, indexed edge flows, u128 total and residual source-side cut. Parallel/antiparallel edges retained; loops carry zero. Distinct valid terminals required. |
| Forest LCA: `lowest_common_ancestor::Lca` | Build O(V log(V+1)), query O(log(V+1)); O(V log(V+1)) | Validated parent forest, iterative cycle detection and binary lifting. Invalid parents/vertices error; separate trees return None. |
| Suffix automaton: `suffix_automaton::SuffixAutomaton` | Build O(n log 256), membership O(m log 256), distinct count O(n); O(n) fixed-byte states/edges | Byte substring language, empty query included; exact count of distinct nonempty substrings in u128. Deterministic sparse transitions. |
| Huffman codes: `huffman::codes` | Heap O(n log(n+1)) plus emitted code length; O(n) tree plus output | Binary code per original symbol, deterministic ties, nonnegative u64 weights. Empty input no codes, singleton one false bit. Code lengths can make output quadratic. |
| Palindromic subsequence: `longest_palindromic_subsequence::length` | O(n²); O(n) | Generic lawful Eq; one-row interval recurrence returns exact length, not a witness. Empty input zero. |
| Unlimited coin change: `coin_change::minimum_coins` | O(k+(A+1)(k+1)); O(A+1) | Minimum count or None; positive usize denominations, duplicate values harmless. Zero denomination preflight, checked table dimension and fallible reserve. |
| Matrix chain: `matrix_chain::minimum_cost` | O(n³); O(n²), n matrices | Positive u64 dimensions, checked u128 cost. Overflowing candidates are skipped; CostOverflow only when final optimum cannot fit. Empty chain zero, zero dimensions reject. |
| A* paths: `a_star::shortest_path` | O(V+E+(V+E) log(V+E+1)); O(V+E) | Directed u64 weights and u64 heuristic vector; validates all endpoints, h(goal)=0 and every consistency inequality before search. Returns optional Path with checked u128 distance and vertex witness. Arbitrary inadmissible heuristics reject; deterministic ties do not promise a lexicographically smallest path. |
| Two-SAT: `two_sat::{Literal, solve}` | O(V+C+V log(V+1)); O(V+C), V variables/C clauses | Clause pairs of indexed positive/negative literals; optional satisfying Boolean vector, None for unsatisfiable. Checks doubled node-count overflow and every literal. Reuses SCC plus explicit condensation topological ranks; canonical SCC IDs alone are insufficient. Empty formula is allowed; assignment is deterministic, not lexicographically minimal. |
| Global minimum cut: `stoer_wagner::minimum_cut` | O(V³); O(V²) | Square symmetric u64 capacities, diagonal ignored. Checked u128 cut total and sorted nonempty proper side containing vertex zero; fewer than two vertices returns None, disconnected graphs have zero cut. Phase ties are deterministic; no globally lexicographic minimum-cut witness promise. |
| Verified rolling-hash search: `rabin_karp::find_all` | O(1+nm) worst case for nonempty patterns, O(n+1) for empty; O(1) plus output | Exact increasing byte offsets with overlaps. Wrapping modulo-2^64 hashes are only a filter: every candidate is byte-verified, including collisions. Empty pattern matches all n+1 boundaries; no Unicode normalization. |
| Horspool search: `boyer_moore_horspool::find_all` | O(nm+256) worst case for nonempty patterns, O(n+1) for empty; O(256) plus output | Byte-alphabet shift table and backward comparisons return all exact offsets, including overlaps. Empty pattern matches every boundary; longer-than-text pattern returns empty. No linear worst-case guarantee. |
| Common substring: `longest_common_substring::longest_common_substring` | O(1+nm); O(m) for nonempty inputs | Generic Eq contiguous Match {a_start,b_start,len}; maximum length then minimum start pair. No match returns (0,0,0). Caller selects element units; no normalization. Checked second dimension; allocation/trait failures follow Rust behavior. |
| Restricted alignment: `optimal_string_alignment::distance` | O(1+nm); O(min(n,m)) for nonempty inputs | Unit insert/delete/substitute/adjacent-transpose costs on Eq slices. Optimal string alignment restricts repeated edits; it is not unrestricted Damerau distance and need not satisfy the triangle inequality. Empty input costs the other length; maximal nonempty dimension panics. |
| Subset sum: `subset_sum::subset_sum` | O((n+1)(T+1)); O(T+1), T target | Nonnegative usize values and target <= MAX_TARGET=1,000,000, checked before allocation even for empty input. Increasing distinct-index witness or None; zero target returns empty witness and zero-valued items are omitted. First discovery is deterministic; no minimum-cardinality guarantee. Typed target/allocation errors. |
| Binomial coefficient: `binomial_coefficient::binomial_coefficient` | O(min(k,n-k) log(n+1)); O(1) | u64 n,k; exact u128 n-choose-k. k>n errors; k=0 or n gives one. Cancel denominator factors before checked multiplication, so Overflow denotes genuine result overflow rather than a removable intermediate product. |
| Interval union: `interval_union::interval_union` | O(n log(n+1)); O(n) | i64 half-open intervals, all validated before allocation. Empty intervals disappear; overlap and touching merge into increasing disjoint intervals. Union includes u128 covered length using widened differences; reversed input reports its index, reserve failure errors, input unchanged. |
| Johnson all-pairs paths: `johnson::johnson` | O(V(V+E)+VE log(E+1)); O(V²+V+E), including output | Directed i64 weights; optional exact i128 distances. Limits V<=1024 and E<=1,000,000 precede global endpoint validation, then global negative-cycle detection. Reweighting stays i128; unreachable negative cycles reject. Empty graph returns an empty matrix; arithmetic errors are checked, allocation failures follow Rust behavior. |
| Prim forest: `prim::minimum_spanning_forest` | O(V+E log(E+1)); O(V+E) | Shares Kruskal Edge/Forest records; u64 weights, checked u128 total, original edge indices in acceptance order. At most 1,000,000 vertices and edges, checked before endpoints. Loops ignored after validation; deterministic heap ties use weight, canonical endpoints and original index. Same optimum as Kruskal need not mean identical edge order. |
| Packed reachability: `transitive_closure::{transitive_closure, Closure}` | O(V² ceil(V/64)+E); O(V ceil(V/64)) including stored result | Reflexive directed closure with `vertices()` and `reachable(from,to)`; invalid queries return None. Limits V<=8192 and E<=1,000,000 precede endpoint validation. Loops/duplicates do not change reachability; empty graph is valid. Allocation failures follow Rust behavior. |
| Adjacent suffix prefixes: `lcp_array::lcp_array` | O(n log²(n+1)) including suffix construction; O(n) | Returns byte suffix order and adjacent LCP vectors of length n; first LCP is zero and no empty suffix is included. Kasai stage itself is O(n); the reused comparison-sort suffix construction determines total cost. |
| Burrows-Wheeler transform: `burrows_wheeler::{transform, inverse}` | Transform O(n log²(n+1)); inverse O(n log²(n+1)+256); O(n+256) | Arbitrary bytes without a sentinel. Equal cyclic rotations tie by original offset; transform returns last column and primary row. Empty maps to ([],0). Inverse checks primary bounds then retransforms to reject unreachable columns/noncanonical periodic rows; an in-range row alone is insufficient. |
| Wildcards: `wildcard_matching::wildcard_match` | O((n+1)(m+1)); O(m+1) | Full byte-string match: ? consumes exactly one byte, * consumes any number including zero. Every other byte, including backslash, is literal; no escapes, Unicode decoding or filesystem semantics. Empty text matches precisely all-star patterns, including empty. |
| Bounded knapsack: `bounded_knapsack::{Item, bounded_knapsack}` | O(items+(C+1)(B+1)), B binary bundles; O(C+1) | usize weight/count, u128 value and exact optimum without witness. Zero weights select every copy; counts of positive weights are truncated by feasibility. Capacity<=1,000,000, items<=100,000 and updates<=20,000,000 precede allocation and value checks. ValueOverflow denotes an overflowing feasible optimum; duplicate items remain independent. |
| LCS reconstruction: `hirschberg::hirschberg` | O(1+nm); O(min(n,m)+log(max(n,m)+1)), plus output | Lawful Eq inputs; increasing index pairs witness an exact LCS. Each length<=1,000,000 and product<=16,000,000 before allocation, even for empty inputs. Shorter row axis, smallest maximizing split and first singleton row match fix deterministic ties, without global lexicographic minimality. |
| Linear recurrence: `linear_recurrence::nth_term` | O(k² log(n+1)) for n>=k, O(1) for initial prefix; O(k) | u64 seeds/coefficients, index n and nonzero modulus; a[t]=sum c[j]a[t-1-j]. Validates modulus, nonempty order, equal dimensions and k<=4096 before the prefix shortcut. Normalizes inputs and uses u128 products; composite moduli allowed. Allocation refusal is typed. |
| Finite-field convolution: `number_theoretic_transform::convolution` | O(L log(L+1)), L padded power of two; O(L) | Ascending-degree u64 coefficients normalized modulo 998244353. Exact modular output of length a.len+b.len-1; either empty operand gives empty. Checked dimensions and L<=2²³ precede fallible allocation. This is modular polynomial multiplication, not unreduced integer convolution. |
| Hopcroft-Karp matching: `hopcroft_karp::maximum_matching` | O((L+R+E) sqrt(L+R+1)); O(L+R) | Left adjacency lists and right count; one optional right mate per left vertex. Combined vertices and edges each <=1,000,000, checked before endpoints. Duplicates allowed; deterministic optimum without lexicographic guarantee. Iterative paths; allocation failure follows Rust behavior. |
| Blocking flow: `dinic::max_flow` | O(V²E+V²+E) conservative; O(V+E) | Shares `max_flow::{Edge, Flow}`: u64 capacities, u128 total, indexed edge flows and residual source-side cut. V,E<=1,000,000 before source, sink, distinctness and endpoint validation. Parallel/antiparallel edges remain distinct; loops carry zero. Checked arithmetic; allocation failure is not typed. |
| Tarjan components: `tarjan_scc::components` | O(V+E+V log(V+1)); O(V) excluding output | Iterative lowlink without reverse graph; sorted members and components ordered by minimum vertex match the existing SCC API. V,E<=1,000,000 before endpoints. Empty graphs, loops and duplicates supported; sorting adds to linear traversal cost. |
| Unrestricted Damerau distance: `damerau_levenshtein::distance` | O((n+2)(m+2)); O((n+2)(m+2)) | Unit byte insertion/deletion/substitution/adjacent-transposition, including repeated edits unlike OSA. Empty inputs immediately return the other length. Otherwise checked dimensions precede the 1,000,000-cell cap including sentinels. Allocation follows Vec behavior. |
| Eertree: `palindromic_tree::{build, PalindromicTree, Palindrome}` | O(n log 256) amortized; O(n) | Distinct nonempty byte palindromes in discovery order, first occurrence ranges, overlapping counts and suffix links. | Lyndon factors: `lyndon_factorization::factorize` | O(n) comparisons; O(1) plus O(k) output | Duval scan returns the unique nonincreasing sequence of nonempty Lyndon factors as byte ranges. Unsigned lexicographic byte order, no normalization; empty input has no factors. Allocation follows Vec behavior. |
| Recurrence synthesis: `berlekamp_massey::minimal_recurrence` | O(n²+n log p); O(n), p=998244353 | Normalizes u64 terms, returns minimum compatible recurrence in lag order accepted by Kitamasa. n<=4096 before fallible allocation. | XOR convolution: `fast_walsh_hadamard::{transform, xor_convolution}` | Transform O(N log N+log p) with inverse, O(1) space; convolution O(N log N+log p), O(N) | Exact residues modulo p=998244353. | Hungarian assignment: `hungarian::{hungarian, Assignment}` | O(r²c); O(r+c) | Rectangular i64 costs, distinct column per row, i128 objective and dual potentials. | Minimum cyclic rotation: `minimal_rotation::minimal_rotation` | O(n); O(1) | Returns the smallest byte index among lexicographically minimum cyclic rotations; empty input gives zero. | Shift-And matching: `shift_and::find_all` | O(256+m+n+z), z matches; O(256) words plus output | Exact increasing byte offsets with overlaps; empty pattern matches all n+1 boundaries. | Subset Möbius: `subset_mobius::transform` | O(N log(N+1)); O(1) | In-place signed subset inclusion-exclusion, inverse of subset zeta on normalized residues over any nonzero u64 modulus. ## References and adapter limits

The implementations are original. All optimizer tolerances are finite, positive and absolute. Convergence is checked before budget exhaustion; zero budget evaluates the initial iterate. The LASSO residual is KKT infinity violation, not the quadratic Euclidean gradient norm or coordinate error. Optimizers map checked reserve failures to allocation errors; standard allocations elsewhere may panic/abort.

Decoded byte output is capped at `min(max_output,65536)` for BPE, LZ77, LZW and patch application. Codec streams may have multiple encodings for the same bytes. Token IDs are not bytes and need an explicit reversible representation before passing through a byte codec.

Interpolation has no hard sample-count cap. Nonfinite checked intermediates return errors. Quadrature budgets count callback calls, require complete levels and preserve call order; callback panic propagates. Interpreting repeated calls as an integral assumes a deterministic integrand. Tanh-sinh may report geometry stagnation before its first complete level; its initial zero value is then a sentinel.

Gaussian complexity includes the augmented right-hand-side column and row processing: zero variables still require `O(m)` work/storage. Field products normalize inputs before multiplication and fit `u64`; this exact arithmetic does not extend to FFT rounding. Polynomial/subset/field identities establish no universal floating-point percentage accuracy.

Numerical residuals measure the stated reconstruction, eigenpair, orthogonality or marginal discrepancy; they are not universal relative solution-error guarantees. Transform inverse identities also require intermediate coefficients to satisfy the next call's magnitude cap. Local polynomial reproduction does not establish denoising accuracy against an unknown signal. Standard allocations may panic/abort; checked linear-algebra reservations and propagated QR failures have explicit allocation errors.

The supported surrogate caps remain 1%, 2%, 5% and 10%, with an explicit metric/domain/evidence requirement. These modules have no generic accuracy profiles, and profiles above 10% are unsupported. They are not automatically substituted into Mova.
