# algorithm-biconnected-components

## Domain
Finite materialized ordered graphs and machine-sized indices, fixed input, successful allocation. Observations are returned Result values; allocator failure and wall-clock timing are outside the relation.

## Forward
Validate endpoints in edge order, u before v, through bridges::adjacency. Partition non-loop edge identities by the equivalence relation generated by membership in a common simple cycle; parallel edges form a two-edge cycle. Each loop and each bridge is a singleton. Isolates produce nothing. Return sorted IDs in blocks ordered by minimum ID.

## Cost
O(V+E) time and auxiliary space, including adjacency, vertex state, edge stack, labels and output. Each adjacency entry is consumed once, each non-loop identity pushed and popped once, and canonicalization scans identities once without sorting. Validation is O(E) before V adjacency allocation. All counts/indexes fit materialized vectors. Explicit stacks avoid recursive DFS.

## Invariant
Discovery numbers are unique. low[v] is the minimum discovery reachable by descending the active DFS subtree and at most one ancestor back edge. The pending edge stack contains precisely discovered non-loop edges not assigned to a completed block. Parent exclusion uses identity, not endpoint, preserving parallel edges. Every input edge receives one label. The final scan transports labels into consecutive block indices in first-ID order.

The behavior complement is (D x Y) minus R, including wrong memberships/counts, malformed canonical outputs, wrong errors and wrong precedence. This is a specification complement; correspondence to source is partial and is not a proof.
Domain and observation scope are those above; assumptions are fixed inputs, successful allocation and trusted compiler/library. Evidence: model.md#evidence. Status: partial_source_derived_model.

## reverse-reconstruction
Type: reverse_reconstruction. For partition P, retain all vertex counts and ordered endpoint assignments whose cycle-equivalence classes, singleton loops and bridges equal P. A singleton does not distinguish a loop from a bridge, and no endpoint is uniquely recoverable. Error fibers fix only the first invalid endpoint and preceding valid endpoints.
Domain and observation scope are those above; assumptions are fixed inputs, successful allocation and trusted compiler/library. Evidence: model.md#evidence. Status: partial_source_derived_model.

## orientation
Type: undirected_representation_equivalence. Swapping valid edge endpoint orientations preserves every edge class; invalid endpoint order is deliberately excluded.
Domain and observation scope are those above; assumptions are fixed inputs, successful allocation and trusted compiler/library. Evidence: model.md#evidence. Status: partial_source_derived_model.

## parallel
Type: cycle_membership. Two parallel non-loop identities share a two-edge cycle and therefore a block. Ignoring all edges to the parent vertex would violate this fiber.
Domain and observation scope are those above; assumptions are fixed inputs, successful allocation and trusted compiler/library. Evidence: model.md#evidence. Status: partial_source_derived_model.

## loops
Type: loop_convention. Each self-loop remains its own singleton even at a cut vertex or when several loops share a vertex; the explicit loop convention resolves competing block definitions.
Domain and observation scope are those above; assumptions are fixed inputs, successful allocation and trusted compiler/library. Evidence: model.md#evidence. Status: partial_source_derived_model.

## isolates
Type: isolated_extension. Appending isolated vertices leaves the partition unchanged; empty graphs of any vertex count have zero blocks.
Domain and observation scope are those above; assumptions are fixed inputs, successful allocation and trusted compiler/library. Evidence: model.md#evidence. Status: partial_source_derived_model.

## canonical
Type: identity_transport. An edge permutation transports equivalence classes by the identity bijection, followed by sorting IDs and blocks. First-encounter canonicalization implements this without comparison sorting.
Domain and observation scope are those above; assumptions are fixed inputs, successful allocation and trusted compiler/library. Evidence: model.md#evidence. Status: partial_source_derived_model.

## Composition
Intersect the source projection, forward relation, ordered typed obernants, invariants and finite evidence. Tests constrain observations but do not prove all wiring. Parent library exports and registry integration are checked separately.

For valid G with m edges and an appended edge from an existing vertex to a fresh vertex, the expected public observation is P(G + bridge) = P(G) ++ [[m]]. Traversal must label that bridge separately, and canonicalization must retain prior classes in minimum-ID order. A parallel edge is not such an extension: it can join a former bridge's class. This relation is source-derived and finitely checked, not a universal source proof. Exact traversal labels carry more information than the partition and are not reconstructed by partition equality alone.

## Epoch memory
Prospective predictions were saved before implementation in model.md#prospective. Original code and fixtures; conceptual origin: Tarjan (1972) lowlink blocks and Kahn (1962) topological ordering with standard DAG recurrence. Existing bridges adjacency and topological_sort were inspected and reused. Production checks matched the first implementation; no semantic repair was needed.

## Limits
Allocation failure is excluded. Syntax projection has no macro expansion or semantic resolution. Finite oracles are not unrestricted proofs. An executable approximate surrogate is an explicit gap: no useful certified relaxed metric was established for edge partitions or exact checked counts; the exact oracle is not a speed surrogate.

## prospective

### Prospective model
Finite ordered undirected multigraph; validate endpoints before traversal using bridges::adjacency. Partition non-loop edges by equivalence generated by sharing a simple cycle; parallel edges form a cycle. Loops and bridges each singleton; isolates omitted. Iterative lowlink stack and linear label canonicalization predict O(V+E) time and space. Every edge appears once. Complement includes wrong splits, merges, omissions and errors. Reverse fiber preserves every graph producing these edge classes, not unique endpoints. Allocation failures excluded. No useful relaxed categorical approximant established.
