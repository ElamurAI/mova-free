# Source-scoped typed relations

## behavior_complement

A target-dependent unsupported call excludes Ok; the same unknown call without target excludes Err and returns0 because absence test wins. Rule construction never consults a numeric sample to decide supportedness.

## reverse_reconstruction

Derivative1 admits x+c for any target-free constant expression c on admitted domains. Returned simplified tree and steps do not recover c, original syntax or lost domain conditions.

## product_quotient

Constant factor branches derive only variable-dependent operand. General product is a'*b+a*b'; quotient uses(a'*b-a*b')/b² unless denominator is target-free, then a'/b.

## power_cases

Target-free exponent uses k*a^(k-1)*a'; target-free base uses a^b*ln(a)*b'; otherwise a^b*(b'*ln(a)+b*a'/a). Validity depends on mathematical domain not stored in E.

## chain_dispatch

For one-argument call derive inner first, then select supported outer derivative. Unsupported outer can error after inner steps. Multiple-argument calls reject unless target absence already returned0.

## step_prefix

Sum/product/power steps append before recursive child work, and no rollback occurs on Err. A step list is a prefix trace, not proof that every displayed rule completed successfully.
