## models

## behavior_complement

A rate command cannot immediately assign/add/subtract a cell. It can affect the owner/thing of later ownerless/unitless quantities, so a no-effect-on-later-state relation is excluded. Const-prefixed quantities are skipped before context updates.

## reverse_reconstruction

Set8;Set3 and Set99;Set3 share final cell3. A rate naming owner Sam/thing apple followed by a bare Set3 can share final cells with an explicit Sam/apple Set3, while command histories differ. Final state cannot recover the context-carrying rate.

## context_before_operation

If a rate supplies a nonpronoun subject and nonempty thing, last_owner/last_thing change before the r branch. The next empty-subject/unit description inherits these values despite the rate's zero immediate cell delta.

## query_selection

ask tries target difference before action difference, class sum, share and state. The target-difference branch uses ? and may return None without trying subsequent branches; State template delegates this entire ordering.
