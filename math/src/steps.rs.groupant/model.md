# Typed relations

## behavior_complement

Oracle excludes repeated leaves; calculators reject mismatched declared exact values. legal excludes zero division/negative subtraction. Direct replay trusts caller and can panic. Python-subset parser does not execute Python.

## reverse_reconstruction

One tree can have multiple valid reduction schedules/unused skipped inputs. Scalar answers and index-erasing shape are many-to-one. Greedy duplicate-valued leaf matching cannot recover original occurrence uniquely.

Valid prefix stack length=Shift count-Reduce/Far count; representative=max text index.

## numeric_domain
