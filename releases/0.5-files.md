# Mova 0.5 — the release files

The files that come with Mova 0.5 beside the code, as of 2026-11-05. Each is one `.tar.gz` archive with one top folder, served over HTTPS from <https://research.elamur.ai/download/0/0.5/> and by BitTorrent (a `.torrent` file and a magnet link for each). Every torrent has the HTTPS file as its web seed (BEP 19), so it completes even when no peer is online. Trackers: `udp://tracker.opentrackr.org:1337/announce`, `udp://tracker.torrent.eu.org:451/announce`; the DHT too. The release page: <https://mova.elamur.ai/free/en/releases/0.5/>. The same data, for programs: [0.5-files.json](0.5-files.json).

Mova fetches them itself: `mova` is the binary of `tools/modules`, which `install.sh` builds as `target/release/mova` and runs with the first line. From the repository root:

```sh
target/release/mova fetch 0.5                       # the required files (the model), over HTTPS
target/release/mova fetch 0.5 all --via torrent     # every file, from its .torrent (web seed, piece check)
target/release/mova fetch 0.5 corpus --via magnet   # from the magnet link (the .torrent from its xs source)
```

To call it as plain `mova`, put it on the PATH (default target folder; with `CARGO_TARGET_DIR` set, use `$CARGO_TARGET_DIR/release` instead): `export PATH="$PWD/target/release:$PATH"`.

Whichever way, the archive's SHA-256 must equal the one below, or it is refused and nothing is unpacked. `mova fetch` does not talk to peers; to download from peers, give the .torrent or the magnet link to a BitTorrent client and then run `target/release/mova fetch 0.5 ID --archive FILE`.
