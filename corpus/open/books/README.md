# Books

The full texts of the books Mova reads in its school's books course, from
[Project Gutenberg](https://www.gutenberg.org/), one plain-text file per book (`pgNNNN.txt`, NNNN is the Gutenberg
ebook number: the original is at `https://www.gutenberg.org/ebooks/NNNN`).

| File | Book |
|---|---|
| `pg11.txt` | Lewis Carroll, *Alice's Adventures in Wonderland* |
| `pg2781.txt` | Rudyard Kipling, *Just So Stories* |

**Changed:** the Project Gutenberg header and footer (licence boilerplate and trademark) are removed; the text itself
is unchanged.

**Source:** public domain in the USA, as marked by Project Gutenberg. Copyright terms differ between countries: if
you are outside the USA, check the status of a book (the author's dates) in your country.

**How Mova uses it:** the books course of Mova's school retells each book in lessons of 3–4 pages with questions on
everything read so far; the lessons' sentences are in the agreed school treebank.
