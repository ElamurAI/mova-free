# Qagen synthetic integration harness — prospective model

The finite forward model is an explicit composition of pure production functions: supplied Para/Pick/skip -> select indices -> ordered Para references -> prompt body and gate coordinates. A second observation joins schema and Pick rule to prompt constraints and accepted/rejected supplied TSV. The supplied TSV is a synthetic independent witness, not generated by the prompt. These four named tests do not constitute one live teacher pipeline; no corpus, DuckDB, teacher, parser or database runs are involved.

The domain consists of tiny valid in-memory paragraph vectors, unique doc#para identities, consistent synthetic word counts, positive sentence weights, ordinary finite sizes, and literal TSV. Sentence IDs and source paragraph numbers deliberately differ from local numbering. Selection consumes skip keys, not Pick.exclude file paths. Fixture metadata is supplied, not read_paras acquisition evidence.

First obernant — behavior_complement: selected outputs exclude ineligible and skipped identities; prompts exclude source sentence IDs and skip payloads; gate local p/anchor references exclude source paragraph/sentence coordinates. V2 rejects explicit spans from nonanchor sentences and context, and punctuation-changed spans. Closed schema excludes invented labels. Rule V1 intentionally has a larger explicit-answer acceptance domain. Advisory paragraph notes do not imply pair rejection. Prompt-only semantic constraints such as question quality and answer length remain outside the implemented gate guarantees.

Second obernant — reverse_reconstruction: a gate (p,anchor) and the ordered batch recover the source (doc,para,sent_id) for that observation; the gate result alone cannot recover those identities. Quotients introduced by case/quote/whitespace normalization admit multiple raw texts; the ambiguity witness uses distinct raw sentences and IDs with the same normalized span. Selection output is compatible with many rejected input paragraphs and cannot recover excluded content. Quota observations are compatible with many size/cap inputs; no unique inverse is claimed.
