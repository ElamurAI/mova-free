## reverse-reconstruction

Type: reverse_reconstruction. Named check: all named joins.

A repaired explicit span identifies compatible sentences/anchors but not a unique old answer; implicit output preserves the chosen old answer and anchors but loses generating prompt provenance. Lemma coverage is many-to-one in forms, order and content labels. Validation errors retain many malformed antecedents; no inverse dataset reconstruction.
