# qagen-run-tests

## forward
Synthetic Job and local files exercise six resume states and three Unix metadata-error branches without teacher calls.

## invariant
Fake prompt panics if reached; scratch directories isolate ordinary tests.

## behavior-complement
Universe: finite supplied values and filesystem observations, return values, errors and writes in this scope. Tests do not exercise scheduler calls, cap concurrency or crash recovery.

## reverse-reconstruction
F^-1(y) contains all compatible inputs and initial states yielding y. Equal outcomes constrain only tested states; failing label localizes a violated branch rather than uniquely recovering a bug. No complete inverse solver or unique recovery claim.

## cost
Bounded constant local files and metadata operations.

## composition
State table joins strict/legacy lookup in normal states; self-links distinguish their error policies and both need probes.

## table-oracle
Independent raw/retry match predicts stages 1,0,2.

## fault-witness
Unix self-links force metadata ELOOP without permission assumptions.

## mutation-gate
Three compiled exists substitutions fail named assertions; original bytes restored.

## profile-repeat
Normalized debug and release per-test outcomes compared twice, excluding timings and thread IDs.

## checks
Finite synthetic Rust tests in owned sources; broad offline qagen lib suite twice per profile, explicitly skipping lemma::tests::doubt_with_en_model. Compiled production mutations reach named assertion failures. Exact outcomes and hashes are in the file groupant ../model.md#evidence.

## epoch-memory

Prospective model saved before repairs. Old-code witnesses demonstrated token overflow, JSON null from float overflow, premature report replacement, and masked metadata errors. Ordinary output keys, finite negative history and legacy Option lookup semantics are preserved. Scheduler was not redesigned.

## limitations
Partial source models and finite observations, not proof of all concurrent/filesystem states. Syntax projection is partial; macros opaque. Allocation failure, races and crashes may prevent completion. No live teacher/model/corpus/database was used. No useful certified metric for a numerical surrogate of these error-sensitive operations was identified; executable approximant is absent, with no invented error budget or speed claim.
