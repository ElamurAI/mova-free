# qagen-report-gather

## forward
Gather ascending batches through strict retry-first lookup and gate; normalize rejection kind and compute lexical support/percentages.

## invariant
Missing batches retained separately; gate-valid pair coordinates map to the same paragraph list. Empty support answer and percentage denominator return zero.

## behavior-complement
Universe: finite supplied values and filesystem observations, return values, errors and writes in this scope. No semantic answer guarantee or anchor repair. Public support requires valid anchors; direct invalid Pair can panic.

## reverse-reconstruction
F^-1(y) contains all compatible inputs and initial states yielding y. kind collapses digit runs/quoted interiors; support collapses words to a ratio. Gather omits raw formatting while retaining gated rejections. No complete inverse solver or unique recovery claim.

## cost
O(P log B + raw/gate costs); support builds anchor-word HashSet and scans answer tokens; kind O(reason bytes).

## composition
Strict lookup errors stop gather before substitution; gate supplies valid coordinates; support operates on token sequence versus anchor-word set.

## normalization
ASCII digit runs ->#; quoted contents ->ellipsis, with unmatched quote governed by boolean state.

## support
Repeated answer words count separately; anchor pool is a set.

## missing-batch
Missing final path records batch ID and continues; read/metadata errors abort.

## coordinates
its[x.p-1] and p.sents[k-1] depend on gate invariants, not independent bounds checks.

## checks
Finite synthetic Rust tests in owned sources; broad offline qagen lib suite twice per profile, explicitly skipping lemma::tests::doubt_with_en_model. Compiled production mutations reach named assertion failures. Exact outcomes and hashes are in the file groupant ../model.md#evidence.

## epoch-memory

Prospective model saved before repairs. Old-code witnesses demonstrated token overflow, JSON null from float overflow, premature report replacement, and masked metadata errors. Ordinary output keys, finite negative history and legacy Option lookup semantics are preserved. Scheduler was not redesigned.

## limitations
Partial source models and finite observations, not proof of all concurrent/filesystem states. Syntax projection is partial; macros opaque. Allocation failure, races and crashes may prevent completion. No live teacher/model/corpus/database was used. No useful certified metric for a numerical surrogate of these error-sensitive operations was identified; executable approximant is absent, with no invented error budget or speed claim.
