A single scalar dimension means square, no numeric arguments means 1x1, empty dimension vector means 0x0. default_dim chooses rows unless rows==1; dim_arg absent/empty/char yields None.

#### dimensions

Filter char values, dispatch by numeric argument count, map dimensions with NaN rejection then clamp/floor/saturating cast; constrain higher dimensions to one.

Boundary: The helper returns a pair only and does not allocate the requested matrix.
