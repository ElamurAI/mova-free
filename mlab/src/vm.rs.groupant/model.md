## invariant

### Invariant

Under compiler-generated valid prototypes, native/fallback paths share error text and value semantics on tested fixtures. Matrix fast indices require positive integral in-bounds coordinates; mutation uses Rc::make_mut. Function pools clear registers/loops after calls. No general verifier validates arbitrary public Proto/Op values.

#### Cost

Compile costs AST traversal, string linear dedup and sorted function/workspace names; execution costs dispatched instructions plus delegated kernels, sync list size and COW copies. Range iteration avoids full range materialization on real scalar path. Registers u16, jumps u32, some argument positions u8; no universal overflow bound; tmp asserts register budget.

## models

# Typed models

## behavior_complement

A failed fast scalar/matrix guard must delegate rather than fabricate an in-bounds index. Fallback errors do not discard synchronized prior writes. Native instruction count excludes fallback statements but does not prove semantic equivalence or absence of dynamic fallback.

## reverse_reconstruction

For output O, preimage consists of compiler-generated programs, initial frames and fault states yielding O. Many source programs compile to observationally equivalent traces. Scalar Reg::F(-0) retains its f64 sign; Reg::L only represents canonical logical 0/1.

## representation_transport

Reg::from_value packs 1x1 real double into F and bit-exact canonical logical 0/1 into L; other values remain V. U.to_value=None. Allocation identity is outside observation.

## fallback_transport

sync_out moves selected registers to current frame, removes U names; sync_in removes frame values back into registers. Frame-sensitive statements synchronize all known vars. Dynamic table/string evaluation uses same round trip.

## compiler_limits

Temporary allocation asserts top < u16::MAX; variable enumeration and loop/index casts have no complete public bound certificate. Public malformed bytecode can panic. Supported domain is valid generated code within limits.

## floating_coordinate_gate

Scalar arithmetic is IEEE f64; negative base fractional powers delegate complex arithmetic. Matrix coordinates are 1-based integral within rows/cols, offset=(j-1)*rows+i-1. NaN fails bounds; COW preserves aliases.
