; mlab — frozen scenario suite v1 (clean room, 26.09.2026).
;
; Format. A block starts with the line «### id | category | title». Then code in the mlab language, then the line «---»,
; then the expected output: each line prefixed with «> » (an empty line — «>»); «>* text» — a line
; that starts with «text». The output is the merged stream in order of appearance: regular output,
; «warning: …», «error: …». Each scenario runs in a fresh interpreter with the default seed.
;
; Where the expected output comes from. Language behaviour — per the public MATLAB/Octave documentation (syntax, semantics,
; output format: format short — 5 significant digits, aligned columns). Values — from identities and exact
; answers (A·inv(A) = I, A·V = V·D, U·S·V' = A, Fibonacci, exact roots), not from other programs:
; there is no Octave on the box. Where a number depends on rounding, the scenario prints a check «< tolerance» (1/0).
