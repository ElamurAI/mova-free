# Table of LaTeX math-mode commands. build.rs compiles it into code (table.rs in OUT_DIR):
# the enums Sym, FracKind, Accent, Font, TextStyle, Stack, XArrow, EnvKind and constant `match`es
# (command name → Entry, character → Sym, environment name → EnvKind). Nothing is read from disk
# at run time. A duplicate form or an unknown kind or class is a build error.
#
# Columns are separated by spaces or tabs. Forms are the last columns; `\name` is a command, a single
# character is a character in the formula. The first form is canonical: `to_latex` prints it.
#   sym   Id  class  text  forms…   — symbol; class: ord op opn fn fnl bin rel open close fence punct inner,
#                                     suffix /d — may be a delimiter after \left/\right; text — for
#                                     plain-text output (Unicode); the text itself, if it is a single character
#                                     not yet taken, also becomes a form (Unicode in the source: ≤ → \le)
#   frac  Id  forms…   — prefix fraction (\frac{a}{b});  infix Id forms… — infix ({a \over b})
#   accent/font/text/stack/xarrow Id forms…  — commands with arguments
#   fontsw Id forms…   — old font switch ({\bf x}), Id is a Font variant
#   class Id forms…    — \mathrel{…} etc., Id is a Class variant
#   env   Id names…    — environment \begin{name}; plainenv Id forms… — the same as a command (\pmatrix{…})
#   other kinds (eqno sqrt root genfrac unicode left right middle begin end opname opnamelim not space spacearg kern ignore
#   ignorearg phantom splice smash color textcolor newcommand providecommand def let declareop
#   rowsep sup sub) — Id «-», behaviour is defined by the parser.
#
# Source of the list — own knowledge of LaTeX/amsmath/amssymb; the KaTeX function list (MIT) is only a reference
# for what to support. Command frequencies in arXiv annotations: data/runs/latex-2026-09-26/.
