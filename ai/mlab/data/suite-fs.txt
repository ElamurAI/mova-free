; mlab file scenario suite (vfs, 26.09): files, directories, paths, OS errors.
; Each scenario — a fresh file system. WASI gate: the same output natively with --fs mem, with --fs dir:<dir> and
; as mlab.wasm in our WASI host (wasi-host, test mlab_wasm_same_output). Only errors with an OS error number —
; texts with an explanation (escaping the root, limits) do not cross the WASI boundary; separate tests check them.
; Expected output checked by hand against MATLAB/Octave semantics (exist 2/7, mkdir of an existing one — a warning,
; rmdir of a nonempty one — an error, readdir with . and .. in byte order) and against glibc strerror texts.

### fs-01 | files | writelines / fileread: round trip
f = '/tmp/a.txt';
writelines({'alpha', 'beta'}, f);
disp(fileread(f))
---
> alpha
> beta
>

### fs-02 | files | writematrix / readmatrix: relative path from the root

disp(isequal(A, B))

> 4,5,6
>
