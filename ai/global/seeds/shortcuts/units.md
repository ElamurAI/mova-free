# Rates and units

**Gist.** "X per Y" is a rate: quantity = rate × number of units; identical units combine only by addition and subtraction (UnitDep, Roy & Roth 2017).

**Examples.** "$2 per egg", "60 miles an hour", "3 books each".

**Sources.** Roy & Roth 2017 (AAAI), "Unit Dependency Graph".

```concept
rate: per each every
total: total altogether together combined sum
```

```link
rate -> multiply : rate × number of units = total
total -> add : total — the sum of the parts
decrease -> subtract : there is less — subtraction
increase -> add : there is more — addition
```

```concept
multiply: times product
add: plus sum
subtract: minus difference
```

```concept
compare: more than fewer less difference
```

```link
compare -> subtract : "how many more / fewer" — the difference, subtraction (Mitra & Baral 2016: comparison)
```

```concept
divide: divided quotient
share: equally among split distribute share
```

```link
rate -> divide : a rate is found from the whole and the number of units by division (whole ÷ count)
share -> divide : sharing equally among several — division
```
