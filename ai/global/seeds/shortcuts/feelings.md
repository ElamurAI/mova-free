# Feelings

**Gist.** A feeling is a reaction to an event: loss, death, separation → sadness; received, escaped, won, met family → joy; attack, threat, darkness, the unknown → fear; deceit, theft, insult, wrong → anger; the unexpected → surprise; was helped → gratitude; disgraced oneself → shame.

**Conditions and exceptions.** A villain rejoices at another's trouble — the feeling depends on whose trouble and whose relief it is; v1 does not distinguish this yet.

**Examples.** The crow was ashamed when the fox took the cheese (shame); the mouse is grateful to the lion for letting it go (gratitude); the king was saddened when the queen died (sadness).

**Sources.** General knowledge; basic emotions (Ekman 1992) — joy, sadness, fear, anger, surprise, disgust; gratitude and shame are social feelings.

```category
joy: happy glad joyful delighted pleased merry cheerful overjoyed relieved proud
sadness: sad sorrowful unhappy grieved miserable heartbroken devastated upset disappointed
fear: afraid frightened scared terrified fearful alarmed worried anxious nervous
anger: angry furious enraged cross annoyed indignant
surprise: surprised astonished amazed
gratitude: grateful thankful
shame: ashamed embarrassed
```

```concept
loss_event: die death lose lost leave part weep cry mourn kill
gain_event: marry find win save rescue return receive reward praise celebrate
threat_event: attack threaten chase roar growl devour
wrong_event: steal trick cheat insult beat mock deceive
help_event: help free release spare
```

```link
loss_event -> sadness : loss, death, separation — sadness
gain_event -> joy : received, escaped, won — joy
threat_event -> fear : attack, threat — fear
wrong_event -> anger : deceit, theft, wrong — anger
help_event -> gratitude : was helped — gratitude
```
