# prag-main-files

## forward
Read supplied CoNLL-U, lowercase lemmas, default absent POS/tag to X; roles emits one-based role rows. World computes requested document keys, retains whole matching documents, obtains pre-sentence summaries with six recent events, then emits only requested IDs in original order.

Domain: finite supplied valid token/tree/label data or isolated saved run files as scoped above. Observation: returned values, named errors, serialized TSV/JSON and public path composition. Operator: the scoped production functions at the manifest source hash. Approximation semantics: partial source-derived behavioral relation, exact on specified fixtures; no numerical approximation cap.

## invariant
Literal headers persist even on empty selection. World restriction equals full-output ID subsequence when document keys are stable and inputs valid. Output preserves input order, while contextual reading sorts document keys and sentence numbers.

## cost
O(input bytes + N log N + delegated frame/context work + output bytes); retains filtered words and output buffer. Reading still parses entire input even with --only.

## behavior-complement
Future context, cross-document context, dropping earlier sentences merely because their IDs were not selected, and lowercase normalization omitted at this adapter are excluded on the supplied fixtures. Universe: scoped inputs paired with candidate observations. This inner exclusion model concerns code behavior, not just test failure; outside the stated assumptions remains unknown.

## reverse-reconstruction
Roles/world are many-to-one observations: original surface casing, unselected documents, many tree details and overwritten output contents cannot be recovered. Compatible inputs must reproduce ordering, selected IDs and context summaries; ID filtering alone does not identify those inputs. Target relation is {(y,x): F(x)=y} within the domain; no implemented complete preimage solver or injectivity claim.

## composition
Preserve shared schema class, source voice, document identity/order and transport descriptor across producer/consumer boundaries. File headers and filtering wrap delegated library computation. Test fragments use public APIs; source module exports alone establish availability only.

## checks
Five binary and two library wave17_models tests exercise literal options/numbers, Unicode segmentation, supplied CoNLL-U role positions, restricted/full world equality, saved-call metadata, schema/serialization/gate and public role/world wiring. Debug and release are each repeated twice; named outcomes compared. Main duplicate-key first-wins mutation and library transport substitution are compiled rejection controls. See file-root ../model.md#receipts.

## limitations
Supplied fixtures are finite; no proof of linguistic correctness, complete exported API coverage or live dispatch. Environment-derived model/effort and role-alone selection are not varied. Syntax projection omits macro bodies and semantic resolution; groupant source hash binds exact bytes.
