# prag-main-report

## forward
Collect supplied saved batches; read saved calls; sum timing/token/cost fields and serialize silver-params.json with shared TEACHER_TRANSPORT plus current environment model/effort. This does not call ask.

Domain: finite supplied valid token/tree/label data or isolated saved run files as scoped above. Observation: returned values, named errors, serialized TSV/JSON and public path composition. Operator: the scoped production functions at the manifest source hash. Approximation semantics: partial source-derived behavioral relation, exact on specified fixtures; no numerical approximation cap.

## invariant
Fresh report identifies Codex CLI through mova-teacher. Call sums and counts reflect saved rows; empty item list has zero accepted/rejected/batches. Historical calls are not reinterpreted or executed.

## cost
O(saved batch bytes + calls bytes + item grouping cost); memory proportional to parsed calls and collection outputs.

## behavior-complement
Claiming Claude CLI for the current transport and synthesizing calls for empty batches are excluded. No transactional multi-file write or overflow guarantee for extreme accounting totals is asserted. Universe: scoped inputs paired with candidate observations. This inner exclusion model concerns code behavior, not just test failure; outside the stated assumptions remains unknown.

## reverse-reconstruction
Aggregate counts and sums admit multiple call sequences and batch contents; current model/effort do not uniquely reconstruct historical per-call environment. Target relation is {(y,x): F(x)=y} within the domain; no implemented complete preimage solver or injectivity claim.

## composition
Preserve shared schema class, source voice, document identity/order and transport descriptor across producer/consumer boundaries. File headers and filtering wrap delegated library computation. Test fragments use public APIs; source module exports alone establish availability only.

## checks
Five binary and two library wave17_models tests exercise literal options/numbers, Unicode segmentation, supplied CoNLL-U role positions, restricted/full world equality, saved-call metadata, schema/serialization/gate and public role/world wiring. Debug and release are each repeated twice; named outcomes compared. Main duplicate-key first-wins mutation and library transport substitution are compiled rejection controls. See file-root ../model.md#receipts.

## limitations
