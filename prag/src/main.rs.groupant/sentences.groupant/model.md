# prag-main-sentences

## forward
Split after maximal runs of ASCII .!?; trim and discard empty pieces; append subsequent pieces without alphabetic Unicode characters to the preceding piece separated by one space.

Domain: finite supplied valid token/tree/label data or isolated saved run files as scoped above. Observation: returned values, named errors, serialized TSV/JSON and public path composition. Operator: the scoped production functions at the manifest source hash. Approximation semantics: partial source-derived behavioral relation, exact on specified fixtures; no numerical approximation cap.

## invariant
Punctuation runs remain attached; nonletter first piece remains a first output. This is heuristic segmentation, not a general sentence tokenizer.

## cost
O(text bytes) time and storage.

## behavior-complement
Splitting punctuation runs or dropping a trailing emoticon is excluded; decimal/abbreviation semantic handling is not claimed. Universe: scoped inputs paired with candidate observations. This inner exclusion model concerns code behavior, not just test failure; outside the stated assumptions remains unknown.

## reverse-reconstruction
Whitespace trimming and inserted joining spaces lose input spacing; all strings yielding the same merged pieces are compatible antecedents. Target relation is {(y,x): F(x)=y} within the domain; no implemented complete preimage solver or injectivity claim.

## composition
