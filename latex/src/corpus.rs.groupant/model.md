## models

## behavior_complement

Zero limit excludes formula parse but not extraction errors. Duplicate IDs exclude later title/abstract. Parse error excludes gate/bridge counts. out=None excludes writes. Selected suffix does not imply valid document.

## reverse_reconstruction

Report preimage contains many documents with differing ignored prose, duplicates and capped samples. Hash cardinalities cannot reconstruct formulas and may collide. Rounded durations and examples lose information; outputs do not recover source paths or macro states.

## limit_order

Extraction bad count precedes limit; return true means a subsequent formula encountered at limit, not just count==limit.

## record_policy

ID-less ignored; first textual ID wins; title before abstract; macros only for tex.

## report_order

Unknown and bridge reasons have lexical tie-break, errors only descending count.

## effect_prefix

unknown.tsv→errors.tsv→roundtrip-fail.tsv→optional bridge-sample.tsv→summary.md can leave partial/stale files.
