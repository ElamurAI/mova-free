## models

## behavior_complement

Failed candidate parse or unequal tree cannot return Ok. Original parse error excludes printing. affected false does not prove arbitrary AST printer correctness.

## reverse_reconstruction

Ok preimage trees equal to reparse chosen print; many original spellings share tree. Mismatch/ReparseError lose original tree, admitting every original producing stored candidate under selected print.

## failure_order

Original parse before print; candidate parse before equality.

## fault_support

SwapFrac unequal parts, DropSup existing sup, DropLast Row len>=3.

## observation

Textual change irrelevant if tree equal; no arithmetic definedness check.

## payload

Mismatch boxes candidate, ReparseError retains Error, Ok discards print.
