You are an INDEPENDENT test author for a LaTeX math-mode parser (clean-room, written in Rust; you have NOT seen its code). It parses math-mode LaTeX (TeX + amsmath + amssymb conventions, as supported by KaTeX/MathJax) into a syntax tree. Tests are frozen before the first run; disagreements are adjudicated independently, so include a case only when you are CERTAIN of the expected verdict under standard TeX/LaTeX semantics.

Documented behavior you may rely on:
- Structural equality ignores whitespace and source positions. Synonym commands are the same symbol (\le and \leq, \ne and \neq, \to and \rightarrow, \gets and \leftarrow, \land and \wedge, \lor and \vee, \lnot and \neg). A single-token argument without braces equals the braced one (\frac12 = \frac{1}{2}, x^2 = x^{2}, \sqrt2 = \sqrt{2}). Order of sub/superscript does not matter (x_1^2 = x^2_1). Infix \over and \choose equal \frac and \binom. \limits/\nolimits, sizes (\big, \Bigl...), spacing (\, \; \quad \!), \displaystyle, \label, \tag, \nonumber, color are dropped (no structural effect). BUT explicit braces around a group of several tokens are structure ({a+b} is a group), and an explicit brace group around a single token as an ordinary atom ({a}b) is NOT required to equal ab — do not test that.
- Scripts attach to the previous atom as in TeX: x^ab means x^{a} b; ^ or _ after a closing brace attaches to that group.
- Unknown commands are kept as "unknown" nodes (not errors).
- Errors (must be rejected): unbalanced { }, \left without matching \right (and vice versa), \begin{X} without \end{X} or with a mismatched \end{Y}, double superscript (x^1^2) or double subscript (x_1_2), a command that requires an argument at the very end of input (\frac{1}), a stray $ inside the formula, a lone \right). Top-level & and \\ are ACCEPTED (treated as an implicit aligned block), and ^2 with an empty base at the start is legal TeX (do not use either as an error case).
- Supported: numbers, Latin/Greek letters (\alpha..\omega, \Gamma.., \varepsilon, \varphi...), \frac \dfrac \tfrac \cfrac \binom \dbinom \tbinom \genfrac, \sqrt[n]{}, primes f'', operators and relations (+ - \cdot \times \div = \ne \le \ge \ll \gg \approx \equiv \sim \simeq \cong \propto \in \notin \subset \subseteq \supset \cup \cap \setminus \emptyset \varnothing \infty \partial \nabla \forall \exists \neg \pm \mp \circ \mid \parallel \perp \angle \triangle ...), \not X, arrows (\to \mapsto \Rightarrow \Leftrightarrow \iff \implies \longrightarrow \hookrightarrow \uparrow ...), delimiters (\langle \rangle \lfloor \rfloor \lceil \rceil \| \{ \}), dots (\dots \cdots \ldots \vdots \ddots), functions (\sin \cos \tan \log \ln \exp \lim \max \min \sup \inf \det \gcd \arg \deg \dim \ker \Pr \arcsin \sinh ...), \operatorname{} \operatorname*{}, big operators with limits (\sum \prod \int \iint \iiint \oint \bigcup \bigcap \bigoplus \coprod), \left \middle \right (with .), environments matrix pmatrix bmatrix Bmatrix vmatrix Vmatrix smallmatrix array cases dcases rcases aligned alignedat gathered split subarray, \substack, fonts (\mathbb \mathbf \mathrm \mathcal \mathscr \mathfrak \mathit \mathsf \mathtt \boldsymbol \bm, old {\bf x} {\cal A} {\rm d}), \text \mbox \textrm \textbf \textit, accents (\hat \bar \vec \tilde \dot \ddot \check \breve \acute \grave \overline \underline \widehat \widetilde \overrightarrow \overbrace \underbrace), \boxed \cancel \pmod \bmod \pod, \overset \underset \stackrel, \xrightarrow[]{} \xleftarrow, \mathrel \mathbin \mathop \mathord, \phantom, \unicode, \newcommand/\renewcommand/\def/\let/\DeclareMathOperator in a document.

OUTPUT: exactly 50 lines, nothing else (no header, no prose, no code fences). Each line has 5 TAB-separated fields:
id<TAB>kind<TAB>a<TAB>b<TAB>source
Formulas are written raw on one line (no surrounding $). A literal TAB is never needed. source is a short reason (TeX rule, amsmath documentation, arithmetic).
Kinds for this batch (ids vmm-tex-051..100; about 20 ok, 15 value, 8 count, 7 macro):
- ok: a is valid, commonly used math-mode LaTeX that must parse WITHOUT errors and WITHOUT unknown commands (use only supported commands listed above; exercise environments, nested fractions, \left...\middle...\right, matrices with \\ and &, cases, \substack, \operatorname, accents, \not, big operators with limits). b is "-".
- value: a is a formula using only numbers, + - \cdot \times \div, \frac, \sqrt{}, \sqrt[n]{}, ^, parentheses (also \left( \right)), and |...| for absolute value; b is its exact value as an integer or fraction p/q in lowest terms (e.g. 7/2), or, only when irrational, a decimal with exactly 12 significant digits prefixed by ~ (e.g. ~1.41421356237). Implicit multiplication like 2(3+4) is 14. Use the standard convention that unary minus binds looser than ^ (-2^2 = -4).
- count: a is a tiny LaTeX document fragment written on one line with the two-character sequence \n standing for a newline; b is the number of math formulas an extractor must find. Delimiters: $...$, $$...$$, \(...\), \[...\], and the environments equation, equation*, align, align*, gather, multline, displaymath (a whole environment counts as ONE formula). Not formulas: \$ (escaped dollar), text after % (comment), \verb|...| and verbatim environments. $...$ does not span a blank line.
- macro: a is a document fragment (one line, \n for newlines) that defines macros with \newcommand, \renewcommand, \def or \DeclareMathOperator and then contains exactly ONE inline formula $...$ that uses them; b is the equivalent formula written without any macros (it must parse to the same structure as the expanded formula; \DeclareMathOperator{\tr}{tr} makes \tr equal \operatorname{tr}).
