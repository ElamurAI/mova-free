# Mova mascot artwork

mova-octopus.webp is Mova's octopus mascot: the engineer with glasses and a scar, a pencil and a notebook of
drawings, calipers, a gear, a laptop and machined parts. It was generated for Mova with OpenAI image generation;
1311 x 1198 WebP with a transparent background. The websites (not this repository) serve derivatives with transparent margins cropped, centred, 4% padding: `mascot.webp` (256 px, WebP 85%, ~24 KB) and `mascot.png` (128 px fallback, ~30 KB), through `<picture>`.
