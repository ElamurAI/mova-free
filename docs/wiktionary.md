# Wiktionary

**Decision (24.09.2026):** open dictionaries start with Wiktionary, **all languages**, Ukrainian and English first. Goal: dictionaries, grammar, etc. **We do everything ourselves from raw dumps.** Ready-made parses (Kaikki/wiktextract) are not used. No rush with words: first we process a couple of words by hand.

## Data

`$MOVA_DATA/raw/wiktionary/<db>/20260901/` — a mirror of the `dumps.wikimedia.org` layout. Provenance, sha1 and reproduction commands are in `SOURCES.md` next to it.

- **198 editions**, one run **20260901** (one snapshot for all languages), 446 files, 8.58 GB bz2.
- Format `pages-articles-multistream` + index `offset:page_id:title`. It contains articles, templates (`ns 10`) and Lua modules (`ns 828`), i.e. everything needed to expand templates ourselves. Streams of 100 pages: you can fetch a single page by title or parse in parallel.
- Large editions are split into parts, each with its own index: en (9 parts, 2.01 GB), fr (6), mg (9), ru (3), zh (3). uk is a single 19 MB file.
- License — CC BY-SA 4.0 + GFDL. Derived data is shared under the same terms and with attribution.
- Streaming processing only; decompressed XML is never written to disk (as is done with Wikidata).

## `tools/wikt-page`

```
target/release/wikt-page $MOVA_DATA/raw/wiktionary/ukwiktionary/20260901 mova "m'yaso" "Shablon:…"
```
(The arguments are Ukrainian page titles, transliterated here; the real call passes them in Cyrillic: `mova` 'language', `m'yaso` 'meat', `Shablon:…` 'Template:…'.)

Prints the raw wikitext for an exact title (with the namespace prefix), with a header `=== title | ns id rev | file`. Titles not found are reported to stderr and the exit code is rc=1. The output was verified byte for byte against `…/index.php?oldid=<rev>&action=raw`.

## How a uk article is structured (first look, "mova")

`= {{-uk-}} =` → sections `===…===`. Grammar is recorded **in template parameters**, not in the text. Template and section names below are transliterated from Ukrainian:

| Section | Carrier |
|---|---|
| Morphosyntactic features | `{{imen uk 1a f una\|sklady={{sklady\|mó\|va}}\|móv}}`: noun, declension type 1a (Zaliznyak's scheme), feminine, inanimate. The declension table is generated by the template. `{{morfo-uk\|mov\|+a\|}}` gives the morpheme breakdown |
| Pronunciation | `{{transcriptions-uk\|móva\|móvy\|Uk-mova.ogg}}` — stress, audio |
| Meanings | `# …` with wiki links, `{{pryklad\|…}}` ('example') |
| Synonyms / antonyms / hypernyms / hyponyms | numbered by meaning, `{{poznachka\|zast.\|…}}` ('label', 'obsolete') |
| Related words | `{{sporidn\|imennyky=…\|prykmetnyky=…\|diyeslova=…}}` ('related': nouns, adjectives, verbs) |
| Translation | `{{pereklad\|\|xx= {{t\|xx\|word}} …}}` ('translation') or `[[word]]` |

## How an en article is structured (first look, "mova", "language")

- One page holds **all languages** that have that spelling: `==Ukrainian==`, `==Russian==`, `==Belarusian==`, `==Old Ruthenian==`… Then come `===Etymology N===`, `====Noun====` and other sections. This is where most of the "all languages" data comes from.
- Grammar of a Ukrainian word: `{{uk-noun|móva<>|adj=móvnyi}}`, `{{uk-ndecl|móva<>}}` (in the dump these are in Cyrillic). The specification in `<…>` (stress pattern, irregularities) goes to a **Lua module**, which derives the paradigm from the stressed lemma. Pronunciation — `{{uk-IPA|móva}}`, etymology — `{{inh|uk|orv|mŭlva}}`, examples — `{{ux|uk|…|t=…}}`, labels — `{{lb|uk|grammar}}`.
- In large articles translations are moved to a subpage `<word>/translations` (`{{see translation subpage|Noun}}`). For "language" it has 529 languages in templates `{{tt|…}}`/`{{tt+|…}}`/`{{t|…}}`/`{{t+|…}}`/`{{t-check|…}}`, for example `* Ukrainian: {{tt+|uk|móva|f}}` (Cyrillic in the dump).
- `wikt-page` on en (9 index parts) takes up to ~2.3 s to find a page.

Conclusion for the parser: the article text itself gives little. The key is to **parse template calls with their parameters** and, for grammar, to **reproduce the logic of templates/modules** (declension) rather than parsing already generated tables. uk and en encode the same grammar differently: Zaliznyak's scheme versus Lua module specifications. Cross-checking the two sources against each other is a ready-made quality control.
