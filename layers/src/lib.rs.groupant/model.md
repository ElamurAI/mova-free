## approximant

### Forward relation

Query detects lowercase explanation substrings. route strips these phrases for global math; if successful clear why only in Answer mode. Otherwise score original query in all domains, stable-sort descending partial comparison, try scores satisfying !(score<threshold) until a solver returns Some (equivalent to score>=threshold for finite scores and finite threshold); else construct empty Escalate answer with context facts.

#### Domain

Valid source-generated AST/values within memory and integer/index limits; deterministic bounded synthetic observations. Arbitrary public malformed representations are outside safety claims.

#### Executable approximant gap

Exact categorical state/dispatch behavior has no supported percentage-error surrogate here.

## invariant

### Invariant

Global math wins over domains; finite equal scores preserve registration order. Exact threshold is eligible. Context logs register and route decisions; escalation does not contact teacher. Nonfinite/malformed scores are not validated.

#### Cost

Query normalization O(text); routing global math cost under Limits5seconds then D coverage calls, stable O(D log D) sorting and attempted solvers plus log bytes. Trait callbacks can be arbitrary; access is metadata, not enforced authorization.

## models

# Typed models

## behavior_complement

Successful global math excludes domain scoring/solve. Below finite threshold excludes solver attempt once sorted boundary reached. Escalate constructs metadata and no remote LLM call.

## reverse_reconstruction

An answer admits many queries and callback states. Domain solve may return arbitrary Route; route output alone cannot recover the selecting domain. Explanation removal makes text normalization many-to-one.

## stable_selection

For finite equal0.5 scores, first registered solver returning Some wins; higher0.9 declining permits next. Equality with threshold is admitted because rejection uses <.

## nonfinite_gap

partial_cmp(None) becomes Equal and NaN<threshold is false; no normalization into0..1. Claims restrict ordering to finite scores.

## mode_projection

Answer clears global why; Explain retains it. Domain answer explanations are returned unchanged, independent of mode.

## effect_metadata

register appends log; route appends chosen/global/escalation log. Access is reported, not filtered. math eval/check can reject parse/eval or independent disagreement.
