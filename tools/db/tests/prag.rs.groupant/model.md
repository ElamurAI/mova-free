## invariant-and-cost

### Pragmatic database fixture and assertions invariants and costs

#### Invariant

Legacy assertions concern actual DB subprocesses and require real CLI. The executed fixture-only check neither creates a DB nor proves rollback/view behavior. Temporary fixture paths are PID scoped.

#### Cost

Fixture representation O(TEXT bytes); legacy test entails many process startups and small SQL transactions/queries, with cost conditional on actual CLI. No production corpus.

Symbolic bounds are source-derived, not measured wall-clock speed or universal complexity proof. Allocation failures, integer exhaustion and concurrency are outside finite evidence.
