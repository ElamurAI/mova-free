## invariant-and-cost

### Prior sentence match and new document join invariants and costs

#### Invariant

Reused sentence doc comes from found candidate and is independent of current newdoc key. New sentence increments created exactly once; only new sentences update local DocCur counters.

Per sentence O(candidate vector + comments + metadata bytes) expected map work. Total suffix probing occurs outside this fragment; counters require nonoverflow.
