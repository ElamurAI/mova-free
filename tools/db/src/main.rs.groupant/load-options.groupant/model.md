## invariant-and-cost

### Load CLI flag consumption invariants and costs

#### Invariant

All flags are value-bearing; a token beginning -- is never a filename. Unknown flag consumes/checks next value before reporting unknown.

#### Cost

O(args bytes + files) parsing; registry and sequential load work are additive and excluded from parser-only check.

Symbolic bounds are source-derived, not measured wall-clock speed or universal complexity proof. Allocation failures, integer exhaustion and concurrency are outside finite evidence.
