## invariant-and-cost

### Stage SQL placeholder boundary invariants and costs

#### Invariant

No filesystem or SQL process action is performed by sql itself; rejected quote returns no substituted string.

#### Cost

O(template bytes + occurrences*directory bytes), allocating one output string.

Symbolic bounds are source-derived, not measured wall-clock speed or universal complexity proof. Allocation failures, integer exhaustion and concurrency are outside finite evidence.
