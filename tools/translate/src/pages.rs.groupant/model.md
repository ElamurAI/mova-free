## descriptant

### translation-flow-pages

chapters gathers Hebrew verse and English sentence pages, sorts numeric verse/sentence coordinates and builds chapter records, then book/chapter sorts. run uses JPS chapter runs for both language page blocks, gives translated/source texts to site decoder, merges translation residual and page Tally. Dir::total adds all three translation residual totals to page cells in LAYERS excluding Meta. add_block increments all counters, records bounded failure ids and merges tallies.

#### Cost

Directory scans+sorting O(Plog P) and file bytes; block comparisons call delegated parser/encoder costs. Dir totals O(residual cells); add_block O(stage cells+page cells+row bytes). No actual page read, annotation or site publication performed.

Integer additions/casts require representability; finite floating inputs where comparisons are modeled. These symbolic costs are not measurements of corpus throughput. No useful cheaper executable percentage surrogate established; future supported caps only 1/2/5/10%.
