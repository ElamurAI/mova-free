## invariant

### Invariant and cost

#### Domain and preservation

Heads within0..n, chunk internal indices valid; counts representable. Initialized Reader from train, not empty Default for chunk fallback. Real file/corpus paths unexecuted. Chunk delimiters restrict serialized concepts.

#### Cost

IBM costs delegated to ibm; ownership/chunk extraction O(nm+m²), BTree counts. Grammar kids O(n²), each subtree scan up toO(n² log n), repeated across verbs O(n³ log n). read head climbs O(nm) conservatively.

Counters and allocation arithmetic must remain representable. String/map costs include compared bytes; finite evidence is not a throughput estimate.

## behavior_complement

Unseen initialized chunks use gloss; unknown gloss cannot create evidence of semantic accuracy. World excludes nonVERB events and roles outside A0/A1/A2.

## reverse_reconstruction

Meta output admits multiple Hebrew forms, glosses, Strong values and nonemitting owners. Given chunk signatures, owner array and token metadata, emitted structure is reconstructible but original verse spelling is not.

## strong_priority

Matching Strong alignment replaces IBM; nearest normalized center then smallest index resolves tie.

## ownership_fill

Unaligned tokens follow previous owner, leading gap follows first owner; all NULL remains None.

## grammar_precedence

Possessive overrides idiom overrides learned chunk; inserts avoid immediately repeated of/the.

## metadata_loss

Reader output retains source span but loses xpos, feats, gloss, mid and frames.
