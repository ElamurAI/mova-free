#### Cost

For N tokens,V interned concepts,E edges, bags and storage O(N log(V+E)); conceptual compact byte count12C+17E+8T excludes BTreeMap/string/allocator overhead. Pair comparison O(P² times reader/logic work per block); training corpora retained, current block metas transient, optional kept metas cumulative. UPGMA recomputes O(n²) cross-pair visits each of n merges => O(n³) distance calls. Rendering squares O(number of metrics*n²) cells plus sort O(n²log n).

Integer additions/casts require representability; finite floating inputs where comparisons are modeled. These symbolic costs are not measurements of corpus throughput. No useful cheaper executable percentage surrogate established; future supported caps only 1/2/5/10%.
