### translation-flow-main

Agg::add increments verses, target token count, exact/gate booleans, chrF and each of three residuals. direct_ok increments only when direct is Some. run_sys filters targets by only, retains records for all target keys, but adds to Agg only when has_src(original key); rotation uses +101 modulo present-source count. block_measure merges block reader+verse tail for meta systems and all verse residuals for baselines, then layout_code; gate conjuncts verse/order/layout checks. CLI dispatches many before eval args, rejects train before creating output, then loads model and corpora, trains tables, measures, writes reports and optionally pages.

#### Cost

Agg O(residual cells+divergence cells) merges; multiset_match O((a+b)log distinct(b)) time and O(distinct(b)) state. run_sys keeps O(target records+outputs), rotation position search O(N²) worst case before codec costs; block_measure scans records per block plus reader DP. Full orchestration costs remain sums of delegated parsing/training/evaluation and sequential file writes, not measured.

Integer additions/casts require representability; finite floating inputs where comparisons are modeled. These symbolic costs are not measurements of corpus throughput. No useful cheaper executable percentage surrogate established; future supported caps only 1/2/5/10%.
