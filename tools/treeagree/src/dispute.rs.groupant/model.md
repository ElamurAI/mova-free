# treeagree-dispute

## descriptant

### Descriptant

disputes starts option A at draft head/relation, then appends unique different heads from witnesses, excluding punctuation and unknown relations; head zero forces Root. parse_answers accepts exactly three whitespace fields and leading S in sentence index; trailing punctuation around letter is stripped. apply accumulates selected non-A alternatives, computes no_worse against draft, then commits whole sentence or returns zero. Repeated picks increase return count even if same word repeats. groups uses chunks(per); by_id overwrites repeated sentence ids.
