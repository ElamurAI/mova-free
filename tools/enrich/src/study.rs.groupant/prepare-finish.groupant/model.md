# Prepared review and candidate finish

## forward

prepare_next requires staged parent, bound seven-output receipt, valid context, at least three nonfrozen sentences and current dictionary before prompt budgeting and directory creation. finish_improve validates baseline/review/candidate lineage, binds four assessment observations and emits an evaluated-candidate receipt.

## behavior-complement

Success with a wrong receipt parent, modified named output, insufficient nonfrozen capacity, changed prior-state hash or an assessment bound to another model is excluded by guards. A preexisting partial directory is possible and fails verification; it is not impossible behavior.

## reverse-reconstruction

A cycle receipt constrains two learner identities, two assessment identities and four grades plus their compatible artifact histories. Existing learned/cross-exam files may have arisen earlier: receipt observations cannot reconstruct unique process attempts or prove a teacher request occurred in this invocation.

## coupling

Sequential relation is prepare; external review/stage; finish, with retained study between review and candidate assessment. Cached artifacts are verified on reentry. Failure retains a prefix, with no rollback; final receipt equality is required if already present. teacher_calls=1 describes outer-cycle accounting rather than an observed call inside finish.

## composition

Scope spans prepare_next, improve wrappers and finish_improve. Filesystem/process failure partitions and environment races remain unmodeled. Cost includes reading/hashing artifacts, optional learner construction and up to two missing cross-exam subprocesses. Existing binding and assessment tests cover portions; no new end-to-end finish or teacher test was executed.

## invariant

Forward and reverse observations refer to the same fixed source snapshot and dependency behavior. Ordering is deterministic for fixed inputs; filesystem/environment stability is assumed where relevant. The complement is an inner bound relative to this fragment's input/output universe.
