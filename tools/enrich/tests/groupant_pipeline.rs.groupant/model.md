## Forward

This source composes real decode_events, stage, status, split_lesson, retention::parse_material, AssessmentContract::new/bind and compare on one synthetic 24-source packet. No teacher process, training, retained state or live exam runs. The packet has self_study=None; this is an interface probe, not study::finish_improve execution.

Successful decoding supplies exactly the review text bound to teacher-reply.json. Staging produces six hashed artifacts with state=staged, complete=false and published=false. Split/parse gives 12 exercises in training and 8 tests plus 4 exams in assessment; assessment contains no teaching/exercise fields. Bound synthetic grades permit gain=1 with an unchanged learner square. Both comparison axes reuse the same assessment.

Six temporal countermodels reject before the test adapter writes review artifacts. Equal parsed JSON with different review bytes rejects. A same-count foreign question projection, foreign candidate label and positive learning counter reject. Repeated staging rejects and preserves lesson bytes and receipt.

## Invariant

Fixture files share packet/prompt digests and one literal review text. Assessment rows retain phase tags, per-kind indices, labels and choice-derived correctness. Identities are joined before comparing counts. Fresh temporary directories have single ownership.

The test-owned save_completed writes review before reply; production review writes reply first. No crash-order equivalence follows. Reports are constructed JSON, not learner observations. Local hashes bind bytes, not a remote identity.

## Cost

Cost sums reached parsing, validation, hashing, assertions and temporary-file operations. For H bytes, S source rows, Q question rows and maximum scan length B, a conservative validation term is O(H+Q*S*B), plus parser/lint and receipt checks. These fixtures are fixed-size; no fitted time model or speedup is claimed.

## behavior_complement

Type behavior_complement. U is the tagged finite fixture/observation space of four tests. R requires Forward equations, rejection gates and output-file frames. U minus R includes accepted invalid traces, changed review bytes admitted, wrong split fields/counts, automatic publication, identity/activity mismatches admitted, or changed outputs after rejected restaging. This target does not enumerate arbitrary process or filesystem failures.

## reverse_reconstruction

Type reverse_reconstruction. A receipt/question projection admits predecessors sharing exact bound hashes and validation constraints. Ignored events, metadata and histories remain ambiguous. A comparison fixes score differences/inequalities, not unique choices or learner execution. A failed observation has multiple compatible faulty gates or inputs.

## terminal_gate

Type temporal_composition. For the six declared countermodels and initially absent output files, decoding error leaves review/reply/staged artifacts absent in this adapter. Production failure records and crash cleanup are outside this frame.

## byte_binding

Type representation_identity. Equal parsed reviews can have unequal bytes. Stage requires literal review bytes equal the decoded result before receipt creation. Pretty-printing witnesses failure of semantic JSON equality as a replacement. Neutral events can vary while the result text is fixed.

## channel_split

Type information_flow. Valid fixture split/parse preserves question phase counts and removes teaching/exercises from assessment. It does not establish unseen passages: training includes source sentences. No held-out quality claim follows.

## grade_square

Type learner_alignment. Binding and comparison retain question projection, per-kind order, passive counters and matching baseline/candidate labels. Foreign same-count projections and mixed candidate labels reject. Structurally valid labels/counters are trusted reports, not process attestation.

## publication_boundary

Type state_projection. Successful staging and a favorable synthetic score comparison do not change published=false or complete=false. No canonical promotion or learned knowledge is implied.

## failed_restage_frame

Type rejected_transition_frame. A second stage call on this completed fixture rejects and preserves lesson bytes and validated receipt. Partial writes, concurrency, I/O failure and process death are outside this narrow frame.
