#### Cost

Prefix×suffix C enumeration and sort O(C log C), plus partial-form scan. With P prefix alternatives,K=min(max_k,U), prefix contexts copy O(K²) units; suffix-context construction occurs separately inside each prefix iteration lacking accepted rest suffixes, costing sum_p O(K_p²), K_p=min(max_k,remaining units). Thus context copying is O(K²+sum_p K_p²), bounded by O((P+1)K²), weighted by copied UTF-8 unit byte lengths. Per-prefix rest concatenation adds O(PB) byte copying.
