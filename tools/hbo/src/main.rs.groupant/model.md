# Typed model catalog

## behavior_complement

flags cannot distinguish a flag-looking next token from a value; malformed chapter part does not reject. score cannot align partial pieces within a mismatched token; same sentence count alone cannot validate identities.

## reverse_reconstruction

Flags map admits duplicate overwritten options and arbitrary order; Part(chapters=None) admits book-only and malformed chapter strings. Tally admits many tree pairs; equal counts/F1 are not recoverable trees or semantic equivalence.

## flag_pairing

At '--k', consume following element even '--other'; no next element yields ''. Duplicate k overwrites. Unflagged positions append plain args. learn_opts defaults parse failures and leaves unsupported options ignored.

## part_membership

holds(b,c) iff book matches and either no parsed range or a<=c<=z. Reversed valid interval admits no chapters; invalid bounds admit all same-book chapters. place defaults missing book/chapter to empty/0.

## alignment_head

Only tokens with equal number of equal-unpointed word forms map predicted position to gold. UAS counts root equality or mapped predicted head=gold head; LAS adds relation equality. Token-count mismatch increments unaligned and skips all mapping.

## cli_effects

choose --study writes study before choose validation and final output; split creates output after reading/preparing all input then writes partitions sequentially; parse annotation can leave temp effects on error. These are static effect models, not executed workflows.
