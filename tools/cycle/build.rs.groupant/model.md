## dependency_rebuild

rerun-if-changed names exactly the file read, and only when it exists: cargo treats a watched absent path as always changed, so a public checkout (no peta/paths.env) would rerun the script on every build. Without the file cargo falls back to its default (rerun when a package file changes); creating the file later is then not noticed until such a change. The dependency declaration does not validate the contents.
