## invariant-and-cost

### Invariant and cost

Outside reviewed IDs, unequal-length versions do not vote, forms/IDs are not alignment keys, and tags/comments come from strongest. For reviewed IDs the final full-tree overlay restores selected tags/comments/heads after voting.

O(V W log V+W²), finite u32 sums assumed; overflow panics debug or wraps release.

No executable percentage surrogate is claimed: effects, categorical acceptance and report text have no justified approximate metric here. Future profiles require a useful metric, zero case, reference and evidence at caps 1/2/5/10%.
