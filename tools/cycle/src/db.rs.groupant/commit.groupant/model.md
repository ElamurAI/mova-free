## invariant-and-cost

### Invariant and cost

Incoming repeated new id adds once then replaces; initial duplicate ids remain except last indexed occurrence. No rollback.

O(old+incoming bytes+events log S), O(old+incoming) memory plus policy validation. Current and history reuse the same incoming snapshot; nontransactional append failures can still leave prefixes.

No executable percentage surrogate is claimed: effects, categorical acceptance and report text have no justified approximate metric here. Future profiles require a useful metric, zero case, reference and evidence at caps 1/2/5/10%.
