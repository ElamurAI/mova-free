## invariant-and-cost

### Invariant and cost

Rendering O(input/output bytes plus paper/card sorting), with repeated totals over at most three splits. String allocations proportional to output; Counts addition assumes no u64 overflow. lang_md requires nonempty cards; Found indices must belong to unchanged Matcher indexes.

papers_md never downloads or links private library folders; only known anthology ids produce ACL links. Empty references return before Papers heading. Rendering cannot certify stats gates that were skipped by a direct caller.

The complement and specialized catalog constrain preserved coordinates and effect boundaries. Empty/malformed domains are only guaranteed where explicitly admitted. No whole-program cost bound follows from a helper bound.
