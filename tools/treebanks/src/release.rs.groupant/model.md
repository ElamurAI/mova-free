## descriptant

### Descriptant

count reads byte lines, trims CR/LF, counts nonempty data runs as sentences, ranges as fused with inclusive under_ranges, dotted ids as empty, other ids as words; final tokens=checked_sub(words+fused,under_ranges). read streams three-component archive paths, accepts UD_ dirs, prefers README.md, rejects code mismatch/duplicate split/no conllu. check_stats compares sentences/tokens/words/fused for train/dev/test/total, requires total, ignores empty nodes.
