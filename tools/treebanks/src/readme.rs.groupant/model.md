## descriptant

### Descriptant

parse stores lines, toggles fence state, collects first machine metadata block with first case-insensitive key, then detects ATX/setext/caps/bare changelog outside fence/meta. body ends at next same-or-higher heading or metadata start. items scans paragraphs/lists, bib brace depth capped at 80 lines, and unmarked reference starts after period with year/word/case guards. docs_page strips exact Jekyll markers/front matter and statistics suffix.
