## behavior_complement

Without residual, excluded claim: arbitrary original spacing, accents or missing forms are recovered. With generated residual valid domains exclude altered original token/tree bytes.

## reverse_reconstruction

Token output alone admits all wrap/gap/NFC antecedents; (tokens,R1) reconstructs original text. Generated R3 plus fixed realized words recovers target words, but not unique parsed source forms.

## nfc_gap_fiber

R1 raw indices count whitespace chunks, gaps count sentence/token pairs, never byte offsets.

## lookup_tie

Equal frequency normalized forms choose lexicographically smallest; unknown lemma returns None, underscore excluded.

## head_transport

Take.from is zero-based; stored head is one-based or zero; inverse alignment remaps heads before patches.

## residual_boundary

R2 joins toggle canonical adjacency; written override precedes concatenated forms; no residual implies canonical forms.
