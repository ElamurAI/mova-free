#### Cost

In streams, N items cost O(N) for fixed16 variety scans and shuffles; the ordered by_verse map costs O(N log(V+1) * L), where V is distinct verse keys and L bounds verse-key comparison bytes. Total emitted bytes B include requested D carrier/quote documents AND additional verse-pair documents, plus mono/lines output. Assembly costs O(B + emitted spans); memory O(N + V + B + emitted spans).

## reverse_reconstruction
