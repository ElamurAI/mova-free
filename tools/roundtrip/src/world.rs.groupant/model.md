### Invariant and cost

Repeated Fact keys cannot create extra world events; Event repetitions remain separate. decode_plain never restores next/quoted by itself. Dedup key is a formatted subset, not injective full-frame identity or logical equivalence.

For encoder-produced residual and matching decoder flags, decode_exact(w,r,nsents) witnesses original sentences. World alone identifies many histories differing in repetition, mention pronouns, attributes, sentence boundaries and next links; no unique original or persistent knowledge state follows.

Let F frames, E entities, Q quote links, B cloned payload bytes, S=nsents and Z=r.empties.len(). Ordered maps add logarithmic lookups; starts can scan O(F^2*(Qmax+1)); decode_in position searches can be quadratic. decode_exact additionally scans the linear empties vector for each requested sentence: O(S*Z+S) time and O(S) output vector storage, independent of F. For S all-empty sentences, F=E=Q=0 and Z=S, yet contains performs S(S+1)/2 equality checks and emits S empty vectors. Deep frame/entity clones add B and recursion cost; no fixed capacity or allocation guarantee.
