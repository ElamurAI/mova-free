## invariant-and-cost

### Invariants and cost

#### Cost

Inline scans can be O(B²) for repeated '['/'<' suffix searches. page lines and concatenation O(B) typical. repeat clones growing Copier each trial: O(total preceding history bytes) per text piece, possibly quadratic. Natural sort keys O(id bytes), sort O(P log P); filesystem rereads selected pages.

Integer additions/products and allocation sizes must fit native types. Floating costs require finite values; no throughput or all-input guarantee follows from synthetic tests.
