# roundtrip-pipeline

## descriptant

### roundtrip-pipeline

groups partitions sentence indices by Unit. run segments and annotates, reads frames with context groups, realizes/world-encodes with world groups, then exact decodes R4->R3->R2->R1; normal mode independently compares starts. damage edits first eligible residual; drop_class maps surviving heads past removed ancestors.

No annotator/model loading, live corpus, full suite, teacher, GPU or persistent-learning evidence. No executable percentage surrogate: categorical codecs/effects need a useful metric before future caps 1/2/5/10%.

Exact recovery with residual is a diagnostic codec observation. It is not evidence of normal generative equivalence, semantic understanding or persistent learning. Production source is preserved; only isolated tests are appended where needed.
