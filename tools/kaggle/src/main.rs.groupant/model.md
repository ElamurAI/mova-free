Eight features produce 36 candidates per row; at most twelve rules are retained, with up to thirteen candidate-building iterations, giving O(13*36*N log(36N)) plus string comparison; groups worst-case O(N^3) dedup scans and is rebuilt per prediction; CV clones O(kN) records before learner costs.
