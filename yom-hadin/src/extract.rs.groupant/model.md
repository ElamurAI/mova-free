## force_priority

First matching copular attr wins before modal. Positive must-pay sanction gives Liability, negative must gives Prohibition, may gives Permission unless negated. No modal/lexical marker yields None; order is not a commutative set reduction.

## ownership_cycle_bound

## adjacent_exception_projection

For adjacent rules with equal source, different sent and next text beginning but if/when, append one exception containing only first clause of each nonempty condition group. Alternative clauses beyond first are lost; not logical negation of the next rule.

## invariant-and-cost

# Invariant and cost

## Invariant

Rule IDs encode jurisdiction, colon-normalized sentence and deontic ordinal; skipped empty roots may leave ordinal gaps. Only existing matched sentences feed postprocessing. Questions produce no rules regardless of frames.

## Cost

For n frames, repeated bounded ancestor walks and scans give conservative O(n^3) plus output bytes; postprocessing BTree grouping O(R log R) plus cloning clauses. Full extract adds parser/model initialization and external data work not measured here.

Symbolic bounds, not timings. Resource exhaustion is not tested.
