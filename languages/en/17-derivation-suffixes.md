# 17. Derivation II: suffixes

A derivational suffix makes a new word from a base and, unlike most prefixes, usually decides its **word class**: *kind → kindness* (N), *read → readable* (A), *modern → modernize* (V), *quick → quickly* (Adv). The suffix is the head of the word. This makes word endings strong cues for a tagger (§10). English suffixes come from two strata, native (*-ness, -ful, -less, -ish, -dom, -hood, -ship, -ly, -er, -en*) and Latinate (*-ity, -ion, -ment, -ance, -al, -ic, -ous, -ive, -able, -ize, -ify, -ate*), which differ in what bases they take, in productivity, and in the sound changes they cause (§9).

This chapter is organized by the class of the result: nouns (§2), adjectives (§3), verbs (§4), adverbs (§5); then suffixes for persons and diminutives (§§6–7), productivity (§8), morphophonology (§9), suffixes as tagging cues (§10), families (§11) and Mova (§12). It follows Jespersen MEG VI chapters XIII–XXV (the suffixes, arranged by sound), Sweet NEG I §§1590–1618 (native) and §§1682–1758 (foreign), and Mova's seeds `en/seeds/morph/wf-noun-suffixes.md`, `wf-adj-suffixes.md`, `wf-verb-suffixes.md`, `wf-ed-adjectives.md` and `adv-ly.md`, which hold exact page references.

## 1. General properties

| property | suffixes | prefixes ([16](16-derivation-prefixes.md)) |
|---|---|---|
| word class | usually changed, set by the suffix | usually kept |
| position of the head | the suffix | the base |
| stress | may shift the stem stress ([03](03-syllable-stress-intonation.md) §5) | rarely |
| spelling changes at the boundary | frequent ([06](06-spelling-rules.md) §§2–6) | rare (assimilation in *in-, con-*) |
| stacking | common: *nation-al-ize-ation*, *care-less-ness*, *hope-ful-ly* | common |

Ordering is constrained: Latinate suffixes generally go inside native ones (*nation-al-ness* is possible, \**friend-ness-al* is not), and the native *-ness, -less, -ful* can follow Latinate bases freely (*activeness, purposeless*), while Latinate suffixes seldom follow native ones (*\*kind-ity*; but *-able* attaches to everything). Reynolds 2026 §8.2.3 (after Biber et al. 1999) names the most frequent suffixes by the class they make: verbs *-ize, -en, -ate, -(i)fy*; nouns *-tion, -ity, -er, -ness, -ism, -ment*; adjectives *-al, -ent, -ive, -ous, -ful, -less, -able*.

## 2. Noun-forming suffixes

### 2.1 From verbs: actions, results, states

| suffix | bases | examples | notes |
|---|---|---|---|
| *-tion, -sion, -ation, -ition, -ion* | Latinate verbs | *creation, decision, information, competition, discussion* | the most frequent abstract-noun suffix; stress on the syllable before (*eduˈcation*); /t → ʃ/, /d → ʒ/ ([04](04-connected-speech.md) §7) |
| *-ment* | verbs (mostly French and Latin; some native) | *government, movement, agreement, payment, development, enjoyment* | event, state, result, instrument, place; Kawaletz 2023 |
| *-al* | verbs stressed on the last syllable | *arrival, refusal, approval, denial, proposal, betrayal* | |
| *-ance, -ence* | verbs (Latin participle stems) | *acceptance, performance, existence, reference, appearance* | Sweet NEG I §1708; *-ancy, -ency* for state: *pregnancy, efficiency* (§1709) |
| *-age* | verbs and nouns | *breakage, marriage, storage, usage; baggage, mileage, orphanage* | Jespersen MEG VI 24.3 |
| *-ure* | Latinate verbs | *failure, pressure, closure, departure* | |
| *-ing* | any verb | *building, meeting, feeling, painting, beginning, clothing* | gerund turned noun; count when concrete ([13](13-verbs.md) §8) |
| *-th* | verbs (native, closed) | *growth, birth* (*bear*), *stealth* (*steal*), *health* (*heal*) | not productive |
| *-ery* (*-ry*) | verbs, nouns | *bakery, robbery, slavery, bravery, machinery, scenery* | place, activity, collective |
| *-ee* | verbs | *employee, trainee, refugee, absentee, escapee* | the person affected; stress-attracting ([03](03-syllable-stress-intonation.md) §5.2) |
| zero (conversion) | verbs | *a walk, a cut, a run, a look* | [18](18-compounding-conversion-minor.md) §3 |

Kawaletz 2023 studied the meanings of newly coined *-ment* nouns (neologisms) and found the same range the literature records for established ones (event, state, result, instrument/means, product, location, patient) plus finer distinctions such as causer, stimulus and experiencer when the base is a psych verb (*bewilderment, enjoyment*) or a change-of-state verb (§7.1.1, table 7.1); the base verb's meaning largely decides which readings are available.

### 2.2 From adjectives: qualities and states

| suffix | bases | examples | notes |
|---|---|---|---|
| *-ness* | any adjective, participle, even phrases | *kindness, happiness, darkness, readiness, preparedness, up-to-dateness* | the most productive; blocked where a noun already exists (*\*possibleness → possibility*); *business* (≠ *busyness*), *witness, wilderness, harness* no longer analysable (Jespersen MEG VI 19.3) |
| *-ity, -ty* | Latinate adjectives | *reality, ability, possibility, security, cruelty, safety, loyalty* | stress shifts (*ˈreal → reˈality*); *-able → -ability*, *-ous → -osity* (*curious → curiosity*) |
| *-ism* | adjectives and nouns | *realism, socialism, racism, heroism, Buddhism, alcoholism* | doctrine, practice, condition; pairs with *-ist*, *-ize* |
| *-th* | native adjectives, with vowel change | *warmth, width, length, strength, depth, truth, health* | closed set; *long → length*, *broad → breadth* ([04](04-connected-speech.md) §8) |
| *-dom* | adjectives, nouns | *freedom, wisdom, boredom; kingdom, stardom, officialdom* | |
| *-cy, -acy* | adjectives in *-t, -te, -nt* | *accuracy, privacy, democracy, fluency, urgency* | *-t → -cy* ([04](04-connected-speech.md) §7) |
| *-ance/-ence, -ancy/-ency* | adjectives in *-ant/-ent* | *importance, silence, frequency, emergency* | |
| *-itude* | Latinate adjectives | *certitude, magnitude, solitude* | |

|---|---|---|

| *-ship* | state, skill, office, group | *friendship, leadership, membership, citizenship, scholarship* (*worship* also a verb) |
| *-dom* | realm, state | *kingdom, fandom, martyrdom* |
| *-ism* | system, practice | *journalism, tourism, terrorism* |

## 3. Adjective-forming suffixes

### 3.1 The main suffixes

| suffix | bases | meaning | examples | notes |
|---|---|---|---|---|
| *-al, -ial, -ual* | Latinate nouns | relating to | *national, cultural, musical, industrial, residential, factual* | the most frequent; *-al* also forms nouns (*arrival, animal*) |
| *-ic, -ical* | nouns (Greek, Latin) | relating to | *economic, historic, athletic, scientific; political, historical* | doublets differ: *economic* (of the economy) / *economical* (thrifty), *historic* (important) / *historical* (of history), *comic/comical, electric/electrical, classic/classical* (Jespersen MEG VI 22.3) |
| *-ous, -ious, -eous* | nouns | full of, having | *famous, dangerous, nervous, curious, delicious, courageous* | always ADJ (EWT: 100% of 244 tokens) |
| *-ful* | nouns, verbs | full of, causing | *careful, useful, beautiful, painful, forgetful, helpful* | opposite *-less* |
| *-less* | nouns, verbs | without | *careless, homeless, useless, endless, countless, tireless* | *unless, bless* are not derivatives |
| *-able, -ible* | verbs (active → passive meaning), nouns | can be X-ed | *readable, washable, acceptable, comfortable, visible, edible* | very productive (*downloadable, googleable*); *-ible* only in old Latin loans; *table, vegetable* are nouns; Jespersen MEG VI 22.6 |
| *-ive, -ative* | Latinate verbs | tending to | *active, creative, attractive, talkative, informative* | *-ive* nouns: *detective, native, relative* |
| *-ant, -ent* | Latinate verbs | doing | *important, different, pleasant, dependent, resistant* | nouns too: *assistant, student* |
| *-ary, -ory* | Latinate nouns, verbs | relating to | *military, ordinary, necessary; compulsory, satisfactory* | nouns: *library, dictionary, factory* |
| *-y* | native nouns, verbs | full of, like | *noisy, dirty, sunny, rainy, sleepy, runny, cheesy* | very productive in speech; also nouns (*city*) and diminutives (*doggy*) |
| *-ish* | nouns, adjectives, numbers | like; somewhat; nationality | *childish, foolish, reddish, tallish, fiftyish, sevenish; English, Spanish, Turkish* | *-ish* as a free word: *Is it done? – Ish.* (Jespersen MEG VI 19.6) |
| *-like* | nouns | like | *childlike, lifelike, businesslike, ladylike* | transparent, often hyphenated |
| *-ly* | nouns | having the qualities of; time | *friendly, manly, costly, cowardly; daily, weekly* | [15](15-adjectives-adverbs.md) §5.2 |
| *-en* | material nouns | made of | *wooden, golden, woollen, earthen, silken* | few, partly archaic (*oaken, leaden*); Jespersen MEG VI 20.4 |
| *-some* | nouns, verbs, adjectives | causing, tending to | *troublesome, tiresome, handsome, lonesome, awesome, quarrelsome* | |
| *-esque* | nouns, names | in the style of | *picturesque, Kafkaesque, statuesque* | stress-attracting |
| *-ese* | place names | nationality, style | *Chinese, Japanese, Portuguese; journalese, legalese* | also a noun of the language |
| *-an, -ian, -ean* | place and person names | of, from | *American, Canadian, Victorian, Shakespearean, Darwinian* | nouns too |
| *-ed* | nouns (and adj. + noun) | having | *talented, bearded, moneyed; blue-eyed, long-legged, kind-hearted* | §3.2 |
| *-ward* | nouns, adverbs | in the direction of | *backward, homeward, inward* (also adverbs, *-wards* BrE) | |

Sweet NEG I §§1606–1614 (native: *-ed, -en, -y, -ish, -some, -ful, -less, -ly, -ward*) and §§1719–1751 (foreign: *-ble, -ic, -ical, -al, -an, -ian, -ine, -ant, -ent, -ar, -ary, -ese, -ous, -esque*); Jespersen MEG VI 19.6–19.8, 20.4, 22.1–22.7, 23.1–23.3, 25.2; seed `wf-adj-suffixes.md`.

### 3.2 *-ed* on nouns

*-ed* attached to a noun, or to an adjective + noun group, makes an adjective "having (a) X": *talented, bearded, moneyed, landed, walled, skilled, gifted*; *blue-eyed* = (*blue eye*) + *-ed*, *long-legged, bad-tempered, open-minded, left-handed, three-cornered, old-fashioned*. No verb stands behind it (*\*to talent*), so these are ADJ (JJ), not participles (Santorini 1990 §4.1: JJ if there is no verb). Old words keep /ɪd/ (*talented, landed*), compounds have /d/ (*blue-eyed*) (Jespersen MEG VI 24.1; Sweet NEG I §§907, 1606; Whitney §194; seed `wf-ed-adjectives.md`).

## 4. Verb-forming suffixes

| suffix | bases | meaning | examples | notes |
|---|---|---|---|---|
| *-ize, -ise* | adjectives, nouns | make, become, treat with | *realize, modernize, organize, criticize, apologize, computerize, prioritize* | the most productive; BrE also *-ise*; always-*ise* verbs (*advise, advertise, comprise, despise, exercise, supervise, surprise*) are not derivatives ([06](06-spelling-rules.md) §9) |
| *-ify, -fy* | adjectives, nouns | make | *simplify, clarify, justify, beautify, classify, intensify, electrify*; *-efy*: *liquefy, stupefy* | Jespersen MEG VI 25.1 |
| *-en* | monosyllabic adjectives (and some nouns) ending in an obstruent | make or become | *widen, shorten, darken, soften, harden, sharpen, sweeten, brighten, frighten; lengthen, strengthen, heighten* | only after obstruents that allow syllabic *n*: no *\*smallen, \*fullen, \*greenen*; Jespersen MEG VI 20.5 |
| *-ate* | Latinate nouns and stems | make, act | *activate, motivate, captivate, hyphenate, vaccinate* | adjective *separate* /-ət/, verb /-eɪt/ |
| *-ish* | (borrowed with the verb) | — | *finish, punish, publish, establish, banish* | not productive (Jespersen MEG VI 19.5) |
| zero (conversion) | nouns, adjectives | many meanings | *to email, to google, to bottle, to dry, to empty* | the commonest way to make a verb ([18](18-compounding-conversion-minor.md) §3) |

The suffixes compete little, because conversion makes most new verbs.

## 8. Productivity

A suffix is **productive** if speakers use it to make new words. Productivity differs widely:

| highly productive | moderately | unproductive (only in existing words) |
|---|---|---|
| *-ness, -er, -ize, -able, -ish, -y* (adj.), *-less, -ful* (adj.), *-ly* (adv.), *-ism, -ist, -ee, -ation* (with *-ize*: *-ization*) | *-ity* (with Latinate bases), *-ment, -al, -ic, -ous, -ify, -ette, -wise* | *-th, -dom* (except jocular *officialdom*), *-hood* (some new: *personhood*), *-ard, -ster, -kin, -en* (adj.), *-ure, -ance* |

Tests: new words in dictionaries and corpora (*cringeworthy, doable, googleable, binge-watchable*); the share of rare words (hapaxes) with the suffix in a corpus; the absence of restrictions on the base. Kawaletz 2023 uses *-ment* neologisms collected from the web and the OED as her evidence; Bauer, Lieber & Plag 2013 (*The Oxford Reference Guide to English Morphology*, not in the library) survey productivity suffix by suffix.

**Blocking**: an existing word blocks a regular derivative with the same meaning: *thief* blocks *\*stealer*, *possibility* blocks *possibleness*, *glory* blocks *gloriosity*, *went* blocks *\*goed*. Blocking is strong for frequent words and weak for rare ones (both *curiousness* and *curiosity* exist, with different shades).

## 9. Morphophonology

Latinate suffixes come with fixed stem alternations ([04-connected-speech.md](04-connected-speech.md) §7):

| suffix | stress | typical stem change | examples |
|---|---|---|---|
| *-ity* | before the suffix | vowel laxing; *-able → -abil-*, *-ous → -os-*, *-c* /k/ → /s/ | *ˈsane → ˈsanity*, *ˈable → aˈbility*, *ˈcurious → curiˈosity*, *eˈlectric → elecˈtricity* |
| *-ion* | before the suffix | /t/ → /ʃ/, /d/ → /ʒ/, *-ceive → -cept-*, *-mit → -miss-*, *-duce → -duct-* | *reˈlate → reˈlation*, *deˈcide → deˈcision*, *reˈceive → reˈception*, *perˈmit → perˈmission*, *proˈduce → proˈduction* |
| *-ic* | before the suffix | vowel laxing | *ˈhero → heˈroic*, *ˈatom → aˈtomic*, *ˈcone → ˈconic* |
| *-ial, -ian, -ious* | before the suffix | /t, s/ → /ʃ/ | *ˈpresident → presiˈdential*, *ˈmusic → muˈsician*, *ˈoffice → ofˈficial* |
| *-al* | weight rule | | *ˈpersonal, enviˈronmental* |
| *-ify* | before the suffix | | *ˈsolid → soˈlidify* |
| *-ize* | none | *-c* /k/ → /s/ | *ˈcritic → ˈcriticize* |
| *-ness, -less, -ful, -ly, -er, -ish* | none | none (only spelling: *y → i*) | *ˈhappiness, ˈcarelessness* |
| *-ee, -eer, -ese, -ette, -esque* | on the suffix | | *employˈee, engiˈneer* |

Some native suffixes cause old vowel changes in a closed set: *-th* (*long → length, broad → breadth, deep → depth, foul → filth, hale → health, wide → width*), *-dom* (*wise → wisdom*), *-en* (*child → children* is plural, not derivation).

Mova's tagger uses suffixes of the word as features and, for unknown words, a suffix-based prior (`en/src/ptag.rs`, `en/src/tag.rs`).

## 12. How Mova handles derivation

- **No derivational analysis.** Each derived word is its own lemma in Mova, as in UD: *happiness* is not lemmatized to *happy*, *creation* not to *create*. The lemmatizer (`en/src/morph.rs`) removes only inflection.
- **Suffixes help the tagger**: the perceptron tagger has suffix and prefix features, and the unknown-word prior (`en/src/tag.rs`) uses suffixes and the dictionary; the AGID expansion of every known lemma gives unknown-word class hints worth 2.2–2.8 points (`en/README.md`).
- **Seeds** state the class each suffix produces and its exceptions (`wf-noun-suffixes.md`, `wf-adj-suffixes.md`, `wf-verb-suffixes.md`, `wf-ed-adjectives.md`, `adv-ly.md`) and add rules: e.g. a word in *-ness* or *-ity* tagged as a verb is suspect.
- **Families are not linked.** A future derivation layer could use CatVar (`$MOVA_DATA/raw/en-catvar`, Open Software License 1.1: "categorial variation" clusters such as *decide/decision/decisive*), NomBank's NOMLEX (`$MOVA_DATA/raw/en-nombank-nomlex`) for nominalizations and their argument structure, and, for testing only, MorphoLex-en (CC BY-NC-SA). The SPECIALIST lexicon (US National Library of Medicine; `$MOVA_DATA/raw/en-gram-specialist-lexicon-2026`, its own terms) records derivational pairs for medical and general English.
