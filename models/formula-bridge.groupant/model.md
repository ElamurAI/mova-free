## forward

Text→extract borrowed bodies/byte offsets→macro-aware parse→structural print/reparse gate→optional restricted Expr/relation transport. CLI/corpus aggregate separate parse/unknown/gate/bridge outcomes; feature math controls API and command branches.

## invariant

Gate Node equality and bridge fold_literals Expr equality differ from numeric truth and definedness: 1/0 may structurally roundtrip but evaluation rejects. Corpus processed formulas partition parsed/errors and parsed partition gate outcomes. CLI success does not imply formula success.

## cost

Repeated unmatched extraction suffixes/nested bridge groups can cause quadratic rescanning. Recursive parsing/printing/conversion add tree/string work. Corpus retains IDs/hashes and one file; CLI tex retains all texts. Ordered file writes are not atomic; no speed claim.
