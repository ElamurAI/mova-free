## forward

lex -> number/unit chunks -> placeholder owner projection -> ordered Interp frames/Pratt -> Expr -> evaluator. Independently steps produces aligned Prob quantities/descriptions; qworld folds exact rational cells and queries them; deduct converts reused quantity DAGs. qread uses separate f64 affine events with leaf provenance, constraint substitution, query and explicit abstain.

## invariant

Source indices bind original quantity occurrences; arithmetic representations are distinct: exact Q cells, fixed Rat Expr and f64 candidate/affine computations. Query acceptance never establishes correctness of annotation. Model/teacher/corpus effects excluded from tests.

## cost

Composition sums annotation, chunk/frame scanning, exact arithmetic, affine map/event scans, O(N*beam*20) stack expansions and O(steps*beam*(N+steps)^2) DAG candidates with feature/cloning/sorting overhead. Dense deduct training arrays2^22 entries each; no benchmark.

## domain

Bounded synthetic valid structures and valid source indices, fixed environment; finite numeric interpretation where required. n<=64 for steps oracle and <=256 DAG pool indices. No external models, teacher, GPU, corpora, held-out or large training.

## behavior-complement

Missing-path guard excludes loader effects; qworld rates exclude cell writes; valid DAG apply excludes invalid numeric interval; unknown-token Interp rejects before frame choice. These scoped exclusions do not compose into general English correctness.

## reverse-reconstruction

Compatible source histories are constrained by quantity occurrence indices and selected frame/action semantics. Overwrites, placeholder loss, duplicate-valued matching and commutative keys make preimages set-valued; scalar output cannot reconstruct original text.

## representation-transport

Exact rational cells cannot be equated with f64 search without conversion/error domain. Preserve source occurrence indices and distinct additive versus overwrite Set semantics.

## search-supervision

steps oracle forbids repeated leaves; deduct gold reuses identical nodes but self-combination search candidates absent, so syntactically accepted gold need not be reachable.

## effect-boundary

Only missing path metadata/tempdir effects exercised; Annotator and frozen suite remain excluded.

## cost-composition

Feature extraction, candidate clone/tree construction and exact arithmetic costs survive composition; no measured speed or global percentage bound.
