# symbolic-arithmetic

## forward

Rat reduces n/d and checks intermediate arithmetic; big Q extends magnitude. Mono SI factor is product of atom factors^exponent; point K=(x+offset)*factor. answer(e)=gate(e,eval(e,fresh_ctx)). arith text->features->subset beam->tree exact replay is a separate big-rational branch.

## invariant

Within safe finite domains, checked arithmetic preserves exact value, unit dimensions and point/delta distinction. A successful eval still requires independent gate acceptance; exact tree replay does not certify language interpretation.

## cost

Evaluation recursive plus aggregate O(k log k) and O(T*2^T) bounded outcome enumeration; subset search exponential in quantity count and quadratic in beam; big arithmetic depends on bit length.

## composition

expr supplies trees; eval joins rat and units with err taxonomy, then external fcheck SI comparison. arith uses big plus external memory NUM_WORDS. understand constructs Expr; solve consumes big helpers. Rat and big are not interchangeable representations: units remain checked i128.

## domain

Bounded synthetic expressions/quantities, normalized representable rationals, finite numeric fixtures, representable i8 unit exponents, n<32 search masks. Public malformed trees/states and huge counts remain explicit gaps.

## limitations

No corpus, teacher, GPU, persistent model or external mutation; approximate branch finite tests do not prove error bounds.
