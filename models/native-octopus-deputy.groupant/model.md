# Native deputy composition

## Descriptant
The abstract deputy interprets ordinary English through actual Mova syntax observations and configured capability rules. Concrete actors and assignments are external configuration. Two supplied adapters establish a bounded read-only starting point; additional installed handlers do not imply general understanding.

## Forward
P -> native UD/frame observations -> all-sentence admission -> named capability plan -> durable reservation -> installed handler calls -> source/output-bound receipt. A refusal instead produces a review-only highest-priority diagnostic candidate with the actual syntax and explicit pragmatic-engine gap.

## Invariant
No planning refusal reaches a handler. No diagnostic candidate is automatic gold or training authorization. Hash identity preserves bytes and provenance, not semantic truth. Completed invocation reuse preserves an old observation rather than asserting freshness.

## Cost
CLI/model loading plus bounded native parsing/configuration matching and at most eight adapter calls. Concrete adapter latency and end-to-end quality remain separate; no speedup theorem.

## Composition
Correct parsing alone does not prove correct intent binding. Correct typed plans alone do not prove handler semantics. Correct transport alone does not establish health. Configured aliases/operations and returned values remain auditable in trace. Future extensions require their own domain and checks.

## behavior_complement
Domain: the supplied CLI/library/adapters under cooperative configuration. Excluded transitions include partial execution of a refused multi-sentence prompt and promotion of raw failure to a learned parser sample. Counterexample: a valid Crab request plus unsupported mutation must remain wholly refused. Evidence: finite negative controls and source wiring.

## reverse_reconstruction
The same concrete capability plan can arise from multiple natural paraphrases. Native traces retain actual prompt identity, but neither plan nor status response identifies a unique intended meaning or system history. Counterexample: polite and imperative requests yield equal plans. Evidence: finite native controls.

## handoff_admission_exclusion
Domain: generated review candidates. Highest priority does not satisfy privacy, held-out or semantic admission. Candidate hashes and actual native observations cannot fill missing pragmatic inference. Counterexample: unresolved “its logs” has valid UD but no referent; it is review material, not a corrected annotation. Evidence: actual source-bound development probe; reviewed downstream adaptation remains outside this groupant.

### 2026-11-05 · document

#### Epoch 2026-11-05 (questions only observe)

Interaction across the deputy and its animals: the deputy decides whether a sentence is a question (frame mood polar or wh, or its own terminator '?' outside a modal request) and then admits only capabilities whose configuration declares `observes`; each animal's `check_capabilities` and the deputy's own load validation refuse `observes` on operations that change state (fetch; describe, pause, resume; draft; check, gap; worker start/stop/restart, consult enqueue, animal_ask). Correct leaves were not enough: every capability passed its own tests while a question about an action ("Is Eel stopped?", "Is the Wikipedia dictionary drafted?") ran it, because the question's root is a request head and the asked verb is also the acting capability's observation. The composed invariant is now: no question sentence yields an acting plan, in every configuration that loads. Configurations without the field still load and refuse questions to undeclared capabilities (fail closed); binaries built before this change refuse configurations that carry the field (`deny_unknown_fields`), so binary and configuration must be deployed together.
