## reverse_reconstruction

Final holder map admits all acquisition/drop histories with the same last surviving assignments; overwritten positions and interleavings are lost. state_lines omits t, me, attributes and several histories. Offset d admits every graph whose first-discovered BFS path has displacement d, including unused contradictory edges. Who-are-you answer n on fast path constrains me=n but not class or history. Ownership fiber: F_H^{-1}(H*)={event sequences e | dom(final_holder(e))=dom(H*) and ∀o∈dom(H*), last_surviving_take(e,o)=H*[o]}. No object outside dom(H*) may retain a holder; H*=empty admits only histories with empty final holder map. Erased intermediate transitions remain free.
