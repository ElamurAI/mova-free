# world-school-scenario-assessment

## forward

Scenario generators create labeled Problems; scenario retries negative answers. Courses designate exercise and scoring sources but call parser/training/I/O. actor_learn_answer enumerates up to six effects for at most three verbs and votes only coordinates shared by all fitting assignments. assessment_fold uses wrapping-u64 repeat hash mixing or u128(index*prime+repeat) modulo folds; zero folds yields None.

## invariant

Positive folds assign exactly one check fold; all other folds learn that row. Equal hashes stay together regardless of index. Noncoprime multiplier/fold pairs may produce empty folds; hash equality is not semantic/provenance identity. Elementary exact template separation does not imply scenario pool separation.

## cost

Fold O(1), no allocation. Effect enumeration at most 6^3=216 solves. Scenario retry lacks a general bound for arbitrary parameters. Parser/teacher/corpus/optimizer costs opaque.

## composition

cross_check_k uses one helper for learn/check predicates. Native u128/masked-u64 oracle tests repeats 0..8, folds 1/2/5/7, extreme indices and equal hashes. assessment_fold is public for parent joins. No dataset, teacher, course, heldout or live parser access.
