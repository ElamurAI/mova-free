# world-school-student-state-updates

## forward

When chosen==target, tick only. Otherwise add one to target and subtract one from chosen for each feature except singleton components of a '+' hint; add three to the full hint target even if absent from text. Tick then adds every current row to its accumulator. No division by tick count occurs.

## invariant

All i64 increments and accumulated sums must remain representable: production updates are unchecked. Generic +/-1 conserves row sum; hint credit adds three. Tick creates accumulator rows even for zero vectors, influencing selection.

## cost

Correction pays feature extraction, O(F log K) updates and O(K log K) tick. Correct predictions still tick all current keys. Aggregated history uses O(K) space without an exercise trace.
