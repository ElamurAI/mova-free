# world-qa3-knowledge-dispatch

## forward

claim_at chooses stage at requested sentence but displays the full state history. claims uses current Who/About/What while selecting historical stage. knows and learns report earliest recorded acquisition, including future acquisition explanations when queried earlier. Dispatch renders frames, levels, branch and event observations; reports preserve supplied row kinds and verdict order.

## invariant

Historical query output is not a strict information-at-time view: future history and current interpretations may appear. These semantics are preserved and explicitly excluded from a no-future-leak claim. Caller must provide consistent event metadata and frame indices. Frozen expectations never mutate supplied world.

## cost

Claim histories O(KH) for K claims with H states; learns adds reveals and knowledge scan. Frames count events per frame O(FE). Reports sum per-query costs and emitted bytes.

## composition

Public joins: World::apply on constructed Cmd/Line values -> answer -> verdict; read_questions -> answers_md on supplied frozen expectations. No neural parser, teacher, corpus, CLI persistence or courses executed.

## behavior-complement

Domain/universe: terminating calls on consistent supplied worlds and well-formed observations in this scope. Inner absent-behavior relation excludes transitions violating the invariant above. This is a source-derived partial exclusion; unknown paths and malformed world states remain outside it. It is not a complement of merely sampled tests.

## reverse-reconstruction

A knowledge answer constrains some recorded acquisition and current labels but does not recover observer belief history or real causality. Different knowledge/reveal histories may share earliest sentence and rendered answer.

## projection-boundary

Report keeps multiplicity and kind for each input row; poly filtering is a main caller responsibility. Native two-row report tests abstention and anchor scores only. Claim/reveal epistemic history and frame-malformation paths are source-inspected, not exercised; no retained school or teacher claims.

All three typed entries bind the manifest revision and scope. Operators are invariant exclusion, output preimage and observation constraint respectively; status is partial source modeling with finite native evidence. Reverse relations preserve all described ambiguity; no complete solver or universal inverse is provided.
