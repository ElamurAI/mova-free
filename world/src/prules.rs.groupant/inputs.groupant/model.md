## behavior-complement

On fixed input tables and terminating dependency calls, excluded outputs include teacher rows at held/dev keys, mismatched teacher text, or unaligned frames retained in judged_only scoring. Invalid correction removes the entire teacher line rather than shifting indices. These are source-inspected inner exclusions, not proof of provenance beyond keys.


## reverse-reconstruction

Given loaded rows, retain every teacher log/item/gold/lesson-prefix read that yields them. Extra held keys, malformed rows and trimmed whitespace can be invisible. Given judged-only counts, retain compatible aligned frames plus all discarded unaligned frames; original link index layout needs the discarded remap. No unique original text or gold log follows.


## gold-filter

load selects dev with gold and teacher outside held/dev key sets, requiring teacher text trim-match. teacher_gold skips short/bad-index rows, rejects a whole line with unreadable shown/corrected frame, appends valid MISSING. judged_only aligns and removes unjudged system frames. This key-based filter was inspected, not exercised on external artifacts; schema/provenance beyond keys is assumed.
