# world-fbench-measurement

## forward

Select in item order by split equality or all and gold key membership. Delegate alignment/counts to prag, aggregate ten role counts, rank worst by F1 then ID, display canonical frame fields including attrs and conditional links.

## invariant

No selected row lacks a gold key. Uniqueness of IDs, valid system output and finite score are caller premises; arbitrary stale course coordinates may panic earlier. show_g is a diagnostic canonicalizer, not a universal serializer for arbitrary public GFrame values.

## cost

Selection O(I log G); aggregation O(I times delegated score cost). Worst sorting O(I log I), diagnostic lookup O(I W). Formatting scales with displayed bytes.
