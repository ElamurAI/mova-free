## model

# Lesson model

## forward

Supplied text -> Lesson -> seeded binding attempts -> expression answer plus filled template. Shared numeric map connects lets, conditions, answer and substitution; the selected partition determines template identity. all() and main_args add filesystem/CLI paths not executed in this slice.

## behavior-complement

U comprises bounded pure supplied-input call traces and observations. Inner complement excludes success violating any shared-map constraint, nonnegative answer gate or selected partition. Union of independent fragment complements would lose wiring constraints; no claim about opaque filesystem behavior.

## reverse-reconstruction

Compose converse relations through a shared Lesson, numeric environment and RNG trajectory. Preserve every compatible rejected-attempt trace. Drawn stores only text and answer, so neither source lesson nor partition nor latent numbers are uniquely recoverable.

## coupling

Public parse, eval, Lesson::{draw,exercises,test,exam}, Rng and Drawn support pure joins. school::lessons adapts Drawn to Problem(text,a=answer,b=0,Add), learns only exercises and scores test/exam; inspected only. A native parent join should preserve these exact text/answer pairs and validate the actual school answer projection. No teacher, parser, live course or retained-state improvement is claimed.

## invariant

Successful observations obey the declared forward relation with the same supplied state and order. Failure is explicit; no hidden label or retained-state guarantee is introduced.

## cost

Compose parse O(bytes) once and draw bounds per requested sample. No optimization proposed; checked arithmetic and i128 range operations add bounded per-operation work while preserving ordinary valid draws. No timing or speedup claim.

## composition

Evaluation and substitution share numeric bindings; field labels choose template containers. Child relations must agree on intermediate state, not merely final counts. Partial syntax binds the source; macro contents are opaque.

## epoch-memory

Initial review predicted arithmetic overflow and finite-pool boundary failures. Old native code failed six named witnesses: overflow, empty templates, name exhaustion, full-width range, reversed range and seed overflow. Narrow repairs retain public signatures; finite observations do not establish arbitrary-input totality. See file model.md#evidence for hashes and repeated results.

## checks

Eight wave12_models tests plus two existing lesson tests. Independent 19 by 19 by 7 arithmetic cases, precedence/eager failure literals, partition/substitution fixtures and exactly 2000 rejected RNG draws. Runtime guard mutations must fail named assertions. Evidence is finite; no whole-world or live course claim.
