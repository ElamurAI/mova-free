## invariant

### Invariant and cost

Ctx starts stdio0..2 and preopen root3, empty env/input/output, fixed seed, 1000ns step and1024 fd cap. alloc_fd fills the first hole at index>=3 before checking vector length. at validates string then directory, rejects empty/absolute, otherwise joins base and relative path.

The invariant is conditional on the admitted transition: alloc_fd cannot choose a later hole while an earlier eligible hole exists; absolute at cannot return a Vfs path. Emission does not promise successful host echo.

Cost: alloc_fd O(F), path clone/join O(path bytes), splitmix O(1), emit O(bytes) plus optional blocking host IO.

No wall-time gain, universal resource bound or atomic rollback is inferred. External Vfs/wasmi/native-mlab work remains separately charged.
